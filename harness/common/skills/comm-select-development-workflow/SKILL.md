# Select the task route

Apply comm-confirm-development-workflow after mandatory startup. Preserve the selected route for continuations.

An explicit request to apply a named skill or plugin to a specific operation selects plain execution with that capability. Accept prose, dollar and slash forms. Apply it directly, including a Superpowers or CE skill. Keep unrelated workflow bodies unread. For an explicitly selected full process or its unambiguous entrypoint, start that process. Для полного процесса Superpowers прочитай файл `harness/common/skills/comm-select-development-workflow/references/full-superpowers.md`.

Если процесс ещё предстоит выбрать, в том числе при запросе сравнить или описать варианты, прочитай файл `harness/common/skills/comm-select-development-workflow/references/menu.md`. Use the request, context and short descriptions. Leave task files and alternative procedures unread until selection. Include every mandatory option. If a missing preference changes the recommendation, ask one question about that preference and wait. Otherwise, explain the recommendation and wait for one route choice. Перед интерпретацией ответа о выборе маршрута прочитай файл `harness/common/skills/comm-select-development-workflow/references/choice.md`.

Apply the chosen procedure within its authorized scope. Request any separate approval at the action that needs it.
