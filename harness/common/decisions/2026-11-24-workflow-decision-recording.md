# Запись решений при согласовании многоэтапных задач

Дата согласования: 2026-11-24. Область действия: разработка шаблона Team Workflow Harness и проекты, которые его используют.

В многоэтапной задаче каждое явно согласованное решение фиксируется до следующего вопроса. В записи указываются принятое решение, его основание и критерий проверки. Связанные решения одной задачи можно вести в одном файле. Решения по самому шаблону сохраняются в `harness/common/decisions`, решения по приложению — в `harness/project/decisions` этого приложения.

Основание: решения о шаблоне должны быть доступны при его разработке, а решения о приложении — в его собственном проекте. Просьба задавать вопросы по одному определяет порядок согласования. При выборе рабочего маршрута учитываются риск задачи и проверки, которые этот риск покрывают.

Критерий проверки: перед следующим вопросом каждое согласованное решение с основанием и критерием есть в постоянной записи нужного пакета. В свежей сессии агент находит запись по задаче и продолжает с первого открытого вопроса.

## Публикация реализации

Пользователь согласовал публикацию точной редакции правила и скилла со статусом «не проверено». Основание — Codex подтвердил запись и восстановление в обоих случаях, а ограничение полной проверки режима `common+project` и статус Claude зафиксированы. Критерий — канонические файлы и установочные копии совпадают с версиями отчёта, проверка копий проходит, итоговый статус остаётся фактическим.
