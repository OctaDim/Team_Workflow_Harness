# Статичный пользовательский вход и память в harness

Принято: 2026-10-04. Область: общая архитектура harness.

Пользователь выбрал общий вход AGENTS.md и минимальный мост CLAUDE.md вместо одного AGENTS.md для обоих инструментов. Дополнительная прямая директива: входная настройка принадлежит пользователю; агентское состояние и накопленные знания развиваются внутри harness.

Причина разделения: накопление опыта не должно переписывать основу, с которой пользователь запускает агентов. Конкретный контракт и разрешённые действия находятся только в [правиле](../rules/user-owned-entrypoints.md).

Уточнение пользователя о ссылке допускает документированный относительный импорт корневого файла. [Claude Code описывает импорт через @path](https://code.claude.com/docs/en/memory#share-one-file-with-other-coding-tools); путь разрешается относительно файла, содержащего импорт. Сам мост не служит местом хранения дополнительных инструкций.

Название категории передачи задач уточнено пользователем: handoffs/. Прежнее название handoff/ заменено в обоих пакетах, индексах и активных пояснениях. Ранее созданные отчёты о проверке прежнего каркаса являются историческими свидетельствами, а не текущей схемой.
