# decisions/ — пояснение для человека

Принятые при разработке решения. Решение, его причина, альтернативы и условия применимости.

Универсальные материалы, применимые в разных проектах.

Пример: Решение хранить переносимые знания в Git вместо личного исключения из Git.

Запись причины помогает следующей сессии не выбирать способ хранения заново.

Пример иллюстративный. Структура создана заранее; рабочие материалы категории ещё предстоит собрать и проверить.
