# Always-loaded rule budgets

For each new/edited always-loaded rule, report path/version, words, word-band,
characters and stock plugin-eval static tokens T. Measure complete unnormalized
UTF-8 text; words are whitespace-separated. Obtain T from that file's budget
component through the authorized human-filtered evaluation, not the directory
total. Record tool/method; missing estimates remain unverified, not zero.
Stock estimation is `ceil(text.length/4)`; JavaScript counts UTF-16 units.
Disclose differences from Unicode-character counts; do not substitute a custom
counter or change analyzer thresholds.

Words: ≤150 good; 151–300 moderate; 301–500 heavy-warn; >500 excessive-fail.
For heavy-warn recommend coherent splitting; excessive-fail strongly recommends
it. Target T≤1000; >1000 warns/recommends remediation; >1200 strongly recommends.
Evaluate both axes independently.

For exceedances present options and await an explicit decision before dependent
work. Permission must cover current rule/version and word/token exceptions;
preserve measurements/bands and other gates. Silence or generic prior permission
is insufficient. Preserve obligations/ownership when shortening or splitting;
measure combined reading, as file splitting alone proves no savings. Re-evaluate
edits. No whole-startup cap or publication waiver is introduced.
