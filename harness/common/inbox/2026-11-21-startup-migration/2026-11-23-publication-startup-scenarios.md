## Ожидания

Штатная команда — `python3 -B harness/common/checks/ensure_entrypoint_links.py --check-rules`. Отдельное восстановление — та же команда с `--restore-rules`.

- Штатная сверка возвращает 0 до первого поиска или чтения. В ответе указано контрольное значение. Рабочая копия совпадает с каноном.
- При расхождении штатная сверка возвращает 4. Агент указывает путь и причину, предупреждает о запрете и предлагает резервный коммит с восстановлением канона. Тестовый запрос остаётся остановленным, контрольная сумма изменённой копии сохраняется.
- При отсутствии самого always loaded правила сверки отдельная команда возвращает 3 с требованием нового сеанса. Восстановленная копия побайтно совпадает с каноном. В новом сеансе штатная сверка возвращает 0 до первого предметного запроса, затем агент возвращает контрольное значение.
