# Сверка защищённых входов и always loaded правил

Codex и Claude Code проверяют оба защищённых входа, `AGENTS.md` и `CLAUDE.md`, по их опубликованным образцам.

Проверка защищённых входов запускается только из этого always loaded правила внутри сеанса. Сразу после получения его полного текста отдельно запусти из корня проверку **без записи**:

```sh
python3 -B harness/common/checks/ensure_entrypoint_links.py --check-start-entrypoints --no-repair
```

Дождись результата. Только после кода 0 отдельно запусти:

```sh
python3 -B harness/common/checks/ensure_entrypoint_links.py --check-rules
```

Запускай проверки для задач только на чтение и при недоступности другого always loaded правила. До первого действия, включая поиск, дождись результатов. При ошибке сообщи команду, код, пути и причину и остановись.

При коде 5 назови отсутствующий вход или нулевой `AGENTS.md`. С разрешённой записью отдельным вызовом выполни `python3 -B harness/common/checks/ensure_entrypoint_links.py --check-start-entrypoints`: он копирует байты из образцов `harness/common/base`. При запрете записи сообщи причину и остановись. После кода 3 нужен новый сеанс. При кодах 5 и 3 сверку always loaded правил и предметные действия в текущем сеансе пропусти.

При расхождении защищённых входов остановись и предложи резервный коммит с восстановлением из канона. Прочитай файл `harness/common/skills/comm-diagnose-harness-entrypoints/SKILL.md` до запроса разрешения. Непустую отличающуюся копию восстанавливай только после явного разрешения и проверенного резервного коммита. Затем нужен новый сеанс.

`--check-rules` сравнивает только always loaded правила. Код 0 подтверждает совпадение, код 4 указывает расхождения. Получи остальные доступные тексты по `comm-instruction-order.md`. При расхождении или пропуске обязательного текста остановись. Один раз предупреди о запрете, назови пути и причины, перечисли пропуски и предложи резервный коммит отличающихся always loaded правил с восстановлением канона. Дождись явного разрешения на конкретную задачу с перечисленными расхождениями или пропусками. Такое разрешение ограничено задачей.

Для отдельно разрешённого восстановления always loaded правил выполни `python3 -B harness/common/checks/ensure_entrypoint_links.py --restore-rules`. Если полного текста этого always loaded правила нет, команду запускает пользователь или средство установки.
