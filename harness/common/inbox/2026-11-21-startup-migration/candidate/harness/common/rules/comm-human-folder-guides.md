# Границы чтения и поиска

До поиска, чтения или загрузки контекста исключи `README.human.md` на любой глубине. Его тело предназначено людям; исключай из контекста, импортов, индексирования для агентов, description и сборщиков. Используй `-g '!README.human.md'` и передавай в cat только явные пути машинных файлов. Глоб `*.md` недостаточен даже при отсутствии пояснений. Личная процедура исключение не отменяет. Программная проверка может читать тела, возвращая только пути, ошибки и результат.

До задачи отдельно перечисли полный установленный набор:

```sh
rg --files --hidden --no-ignore .claude/rules -g '*.md' -g '!README.human.md'
```

Для чтения оставшихся путей используй [comm-instruction-order.md](/harness/common/rules/comm-instruction-order.md). Список включает вложенные и игнорируемые Markdown любых имён. Его полнота и получение текстов — отдельные факты.

Рабочие Markdown-ссылки разрешай от папки файла. Подпись — точное имя цели, включая расширение и регистр. Для соседних папок используй `../`. При изменении проверь переход из каждой установки и канонического файла; расхождение согласуй. Актуальные материалы ищи в соответствующей канонической категории. Исключи поддеревья INBOX и evidence из общего поиска по содержимому. Для выбора заявки сначала извлеки только поля статуса, затем открой применимую незавершённую заявку. Завершённую открывай по конкретному результату, расхождению или вопросу об истории. По такому же конкретному основанию открывай evidence и исторические снимки. Разрешены выбранный актуальный Канидат INBOX и свидетельства, необходимые для его проверки. Историческая или неопубликованная версия не определяет текущее поведение.

Согласованные категории создавай заранее, даже пустые. Каждой новой папке harness нужен `README.human.md` с простым пояснением и примером. В пустой папке пример иллюстративный. Наличие пояснения не подтверждает наполнение или проверку.

При оценке выводи для каждого запуска, клиента, режима и сценария шесть строк: впервые получено нативно, впервые открыто явно, размер списка, число уникальных полностью полученных путей, лишние полные чтения, результат со всеми причинами и фактическими числами. Отмечай способ получения и отдельно наблюдаемое применение. Неизвестные значения обозначай как непроверенные.

Для оценки материалов harness перед инструментами открой [SKILL.md](/harness/common/skills/comm-validate-harness-instructions/SKILL.md).
