# Защищённые входы и память

Защищённые `AGENTS.md` и `CLAUDE.md` — корневые входы Codex и Claude Code. Они доступны агентам и пользователям только для чтения по договорённости harness. Отсутствующий вход или нулевой `AGENTS.md` стартовая проверка восстанавливает из соответствующего опубликованного `harness/common/base/AGENTS.template` или `harness/common/base/CLAUDE.template`. Существующий нулевой `CLAUDE.md` корректен. В `AGENTS.md` единственное требование — прочитать перед задачей все always loaded правила из `.claude/rules/` рекурсивно, кроме `README.human.md`. Claude Code получает их нативно.

При расхождении непустого входа сохрани байты, покажи разницу и остановись до задачи. По явному разрешению через INBOX сначала сделай резервный коммит, затем восстанови указанные входы из опубликованных образцов. Разработка новой редакции, удаление или перегенерация входов — через согласование и отдельную публикацию в INBOX. Запрет прямого изменения действует для генератора, хуков, других агентов, ручных и UI-правок. При изменении редакции входа проверь равнозначность поведения клиентов в каждом режиме установки.

При диагностике прочитай файл `harness/common/skills/comm-diagnose-harness-entrypoints/SKILL.md`. Проверка сообщает: «Прямое редактирование AGENTS.md и CLAUDE.md запрещено договорённостью harness, но технически не заблокировано.» Укажи путь INBOX. Hooks, блокировка записи/коммита и индивидуальная настройка машины не требуются.

Динамическая память — внутри harness; долговременные решения и опыт сохраняй вне временных заявок. Материалы `handoffs/` создавай только по явному поручению. Штатные спецификации, планы, рабочий журнал, временные файлы и постоянные результаты проверок Superpowers остаются по штатным путям. Superpowers возобновляет работу и удаляет собственные временные файлы по своей процедуре с соблюдением согласований и защиты данных harness. Во входах не хранить историю, состояние задач и результаты.
