# Защищённые входы и память

Защищённые `AGENTS.md` и `CLAUDE.md` — корневые входы Codex и Claude Code. Они доступны агентам и пользователям только для чтения по договорённости harness. Источники восстановления — опубликованные `harness/common/base/AGENTS.template` и `harness/common/base/CLAUDE.template`. Существующий нулевой `CLAUDE.md` корректен. В `AGENTS.md` единственное требование — прочитать перед задачей все always loaded правила из `.claude/rules/` рекурсивно, кроме `README.human.md`. Claude Code получает их нативно.

Восстановление входа выполняется отдельно из опубликованного образца. Перед заменой непустого входа проверь согласованный резервный коммит. После восстановления продолжай в свежем сеансе. Изменение самих канонических образцов проходит согласование и отдельную публикацию в INBOX. При изменении редакции входа проверь равнозначность поведения клиентов в каждом режиме установки.

При диагностике прочитай файл `harness/common/skills/comm-diagnose-harness-entrypoints/SKILL.md`.

Динамическая память — внутри harness; долговременные решения и опыт сохраняй вне временных заявок. Материалы `handoffs/` создавай только по явному поручению. Штатные спецификации, планы, рабочий журнал, временные файлы и постоянные результаты проверок Superpowers остаются по штатным путям. Superpowers возобновляет работу и удаляет собственные временные файлы по своей процедуре с соблюдением согласований и защиты данных harness. Во входах не хранить историю, состояние задач и результаты.
