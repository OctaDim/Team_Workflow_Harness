# Полнота контекста до действия

До действия по задаче, включая поиск, получи полные актуальные тексты всех always loaded правил. Запрашивай `comm-entrypoint-links-rule.md` первым, отдельно или в общей выдаче. Ошибки обрабатывай пофайлово, продолжай читать доступное. Если выдача прервалась, сохрани полные тексты и следующим вызовом получи текст сверки, если его ещё нет.

Получив полный текст сверки, сразу выполни проверки даже при ошибке чтения или неполной выдаче другого файла. Дождись результата и получи остальные доступные тексты. Проверь полноту каждого пути и версии, обрезанный текст дочитай в той же версии. При расхождении или пропуске примени порядок остановки из always loaded правила сверки. Допуск требует успешной сверки и полного контекста. Действие до допуска — критическая ошибка.

В диалоге и материалах называй конкретный тип:

- always loaded правило — полный актуальный текст обязателен до задачи.
- короткое always правило с условным скиллом — все ссылки условные.
- короткое always правило с безусловным скиллом — все ссылки безусловные.
- короткое always правило с условным\безусловным скиллом — присутствуют оба типа ссылок.
- контекстный lazy скилл — выбирается по нативным `name` и `description` либо по наступившему условию; требуется полный актуальный `SKILL.md`.
- Защищённые `AGENTS.md` и `CLAUDE.md` — корневые входы соответствующих клиентов.
- Канидат INBOX — версия материала в текущей заявке для проверки и решения о публикации.

Для каждой текстовой ссылки на скилл или ссылки на `SKILL.md` из always loaded правила момент чтения задаёт текст этой ссылки. По безусловной ссылке прочитай файл сразу после получения always loaded правила, до любой задачи. Если та же выдача впервые принесла полный текст `comm-entrypoint-links-rule.md`, сначала выполни проверки из него и дождись результата, затем прочитай обязательный `SKILL.md` до предметного действия. По условной ссылке прочитай файл при наступлении условия, до первого зависимого действия, в том числе в середине задачи. Если в контексте только `name` и `description`, в этот момент получи полный файл. Уже полученный полный актуальный текст используй без повторного чтения. Обрезанный текст дочитай в той же версии. Если получить его невозможно, остановись до зависимого действия, сообщи путь и причину и дождись решения пользователя. При нативном выборе или явном вызове контекстного lazy скилла получи полный текст до применения. Явно запрошенный в Codex скилл применяй после обязательного старта. Получение текста не разрешает действия.

Для навигации по общему пакету при необходимости прочитай файл `harness/common/INDEX.md`. Для навигации по проектному пакету при необходимости прочитай файл `harness/project/INDEX.md`.

При невозможности получить полный текст или повторном полном чтении неизменного файла сообщи ошибку и каждый точный путь, остановись до явного решения. До добавления безусловной ссылки или снятия условия назови файл и изменение, задай отдельный вопрос и дождись явного согласия до записи. Первоначальное поручение его не заменяет; чтение согласованной ссылки отдельного разрешения не требует. В списках указывай always loaded правила и их каталоги перед контекстными lazy скиллами.
