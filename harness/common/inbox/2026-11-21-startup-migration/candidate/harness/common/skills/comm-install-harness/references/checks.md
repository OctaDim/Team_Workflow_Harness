# Проверка переноса
Common обязателен. Перед созданием нейтрального project прочитай файл `harness/common/base/project-skeleton.json`. При переносе только common создай отсутствующий project по категориям этого образца с картой INDEX, человеческими пояснениями и обеими ветками testing/evidence. Перенос common+project сохраняет существующий project побайтно. Частично существующий project не дополняется. Для project-only требуется остановка до записи.

Из корня целевой установки выполни `python3 -B harness/common/checks/ensure_entrypoint_links.py`. Запускай только доверенный обычный файл напрямую, проверив путь и предков без разыменования симлинков. Shared-материалы ставятся из опубликованных канонических rules и полных папок skills. Образы входов — `base/AGENTS.template` и `base/CLAUDE.template` в common. Чтобы определить рабочие назначения, прочитай файл `harness/common/skills/comm-publish-harness-instructions/references/placement-contract.md`. Установщик добавляет проектные записи в `.codex/hooks.json` и `.claude/settings.json` и сохраняет остальные настройки. Для проверки запуска зафиксируй отдельно обнаружение проектных записей, доверие к ним и фактический результат синхронного `UserPromptSubmit`.

Сверить полный набор и байты источников, копий и ресурсов, целостность непустых карт INDEX и отсутствие рабочих START. Проверить обычный и повторный старт в двух независимых установках. Отдельно проверить недостающую, повреждённую и неизвестную копии, конфликт защищённого входа, отсутствие common, незавершённую публикацию и неизменность существующего project. Пользователь принимает решение по каждому конфликту. До изменения общего JSON нужны отдельная common INBOX-заявка, отдельное решение пользователя и подтверждение пользы для всех проектов. Изменение существующего project требует адресного основания.

Зафиксировать клиент, версию, режим установки, команду, фактический исход и ограничения. Проверять отдельно структуру, полное получение текста, применение, нативное обнаружение и бюджеты. До диагностики прочитай файл `harness/common/skills/comm-diagnose-harness-entrypoints/SKILL.md`, до миграции материалов прочитай файл `harness/common/skills/comm-preserve-harness-knowledge/references/material-placement.md`.
