# Проверка переноса
Common обязателен. Перенос только common создаёт отсутствующий нейтральный project по категориям из [project-skeleton.json](/harness/common/base/project-skeleton.json), с картой INDEX, человеческими пояснениями и обеими ветками testing/evidence. Перенос common+project сохраняет существующий project побайтно. Частично существующий project не дополняется. Для project-only требуется остановка до записи.

Из корня целевой установки выполнить `python3 -B harness/common/checks/ensure_entrypoint_links.py`. Запускать только доверенный обычный файл напрямую, проверив путь и предков без разыменования симлинков. Shared-материалы ставятся из опубликованных канонических rules и полных папок skills. Образы входов — `base/AGENTS.template` и `base/CLAUDE.template` в common. Рабочие назначения определяет [placement-contract.md](../../comm-publish-harness-instructions/references/placement-contract.md). При утрате стартового always loaded правила или входа Codex запустить ту же команду отдельно. После восстановления открыть новый сеанс для проверки фактической загрузки.

Сверить полный набор и байты источников, копий и ресурсов, целостность непустых карт INDEX и отсутствие рабочих START. Проверить обычный и повторный старт в двух независимых установках. Отдельно проверить недостающую, повреждённую и неизвестную копии, конфликт защищённого входа, отсутствие common, незавершённую публикацию и неизменность существующего project. Пользователь принимает решение по каждому конфликту. До изменения общего JSON нужны отдельная common INBOX-заявка, отдельное решение пользователя и подтверждение пользы для всех проектов. Изменение существующего project требует адресного основания.

Зафиксировать клиент, версию, режим установки, команду, фактический исход и ограничения. Проверять отдельно структуру, полное получение текста, применение, нативное обнаружение и бюджеты. До диагностики открыть [SKILL.md](../../comm-diagnose-harness-entrypoints/SKILL.md), до миграции материалов — [material-placement.md](../../comm-preserve-harness-knowledge/references/material-placement.md).
