# Диагностика запуска

Сверку выполняют нативные проектные триггеры. Успех подтверждает один проход по SHA-256 защищённых `AGENTS.md` и `CLAUDE.md` и рабочих копий always loaded правил. Ищи результат конкретного события `UserPromptSubmit` в текущем сеансе.

- Если Codex показывает ожидающее одобрение, предложи пользователю проверить проектную запись через `/hooks` и повторить запрос. При выключенном триггере проверь настройки и перезапусти клиент, если этого требует его версия.
- При подтверждённом отказе назови пути и причину из диагностики триггера. Если сработало восстановление, пользователю нужен свежий сеанс. Если есть резервный коммит, укажи его полный Git ID и сохранённые пути.
- При пропуске, аварии или тайм-ауте считай сверку неподтверждённой. Укажи клиент и то, что видно в его выводе или трассе.
- Канонические защищённые входы находятся в `harness/common/base/AGENTS.template` и `harness/common/base/CLAUDE.template`. Пустой рабочий `CLAUDE.md` соответствует пустому канону. Для изменения канона пользователь может открыть отдельную заявку INBOX.
