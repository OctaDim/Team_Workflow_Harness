# Диагностика результата

Запустить из корня доверенный `python3 -B harness/common/checks/ensure_entrypoint_links.py`. При ошибке проверить исходный путь и предков, доступ, тип файлов, наличие common, канонических источников и карт. История Git и INBOX не служат источниками для восстановления.

- След публикации или занятая блокировка: обычный старт остановлен. При прерванном переносе возобновлять тот же одобренный набор в той же заявке. Любое третье содержимое сохраняется для решения пользователя.
- Отсутствующий защищённый вход создаётся из своего образца. Для существующего входа сравнить точные байты, включая окончания строк: пустой CLAUDE.md допустим. Расхождение требует остановки и решения через INBOX.
- Для недостающей или повреждённой управляемой копии установить владельца по опубликованному источнику common или project. Зафиксировать восстановленные пути. Неизвестное always loaded правило требует остановки. Изменять файлы из текущей заявки при обычном старте запрещено.
- После восстановления материала, влияющего на загруженный контекст, завершить текущий старт. Успешный чистый повтор и получение исправленного текста в новой сессии фиксировать отдельно.
- Отказ ввода-вывода или параллельная правка: записать выполненные и ожидающие пути, проверить реальные байты до повтора. Незавершённая публикация имеет свой учёт исходных и одобренных версий.
- При переносе только common скрипт создаёт отсутствующий нейтральный project. Частично существующие данные сохраняются. При неизвестном источнике или коллизии common/project нужен выбор владельца.

В изолированной установке проверить повторный старт, создание входа, конфликт существующего ввода, рабочие копии и порядок восстановления после прерывания. Системные права проверять на тестовой установке. Стартовая проверка сама не устанавливает hooks и не запрещает пользователю редактировать файлы на уровне ОС.
