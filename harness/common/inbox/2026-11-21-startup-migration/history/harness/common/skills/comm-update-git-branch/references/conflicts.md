# Resolve intended behavior

Inspect the common base and both changesets; preserve current approved contracts,
not obsolete code deliberately superseded. Never blanket-select ours/theirs.
Unclear or incompatible intent: show the conflict, propose a resolution and wait.
Database and other protected-domain approvals remain mandatory.

Follow renamed destinations, update affected callers for interface changes, and
regenerate generated/lock files from reconciled inputs using project tools.
Do not assume one side's generated output is the combined result.
Inspect silent conflicts: versions/formats, cache/build IDs and old API callers.
Review actual resolved changes before staging; check unresolved markers and
agreed decisions. Symbols, clean status and no markers alone prove no behavior.
Select checks for both sides' affected contracts, overlaps and dependencies
through existing test owners, not only the old task diff.
