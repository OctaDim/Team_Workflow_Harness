# Inventory the required connections

Identify the intended canonical repository and applicable Git refs/history,
LFS objects, PRs/issues/releases, protections/permissions, apps, webhooks,
CI/runners, deploy-key/credential bindings, automation and current documentation.
Inspect HTTPS/SSH remotes, API/raw URLs and PR links; an owner-name search alone
misses forms and context. Preserve correct emails/person/service names even if old.
Record what the chosen mechanism preserves, changes or requires reconfiguration;
do not assume every integration transfers. Verify important operations safely
within authority, not a production deployment merely to prove migration.
