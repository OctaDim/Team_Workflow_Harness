# Select the task route

Apply comm-confirm-development-workflow after mandatory startup. Preserve the selected route for continuations.

An explicit request to apply a named skill or plugin to a specific operation selects plain execution with that capability. Accept prose, dollar and slash forms. Apply it directly, including a Superpowers or CE skill. Keep unrelated workflow bodies unread. For an explicitly selected full process or its unambiguous entrypoint, start that process. For a full Superpowers route read [full process](references/full-superpowers.md).

When the choice is open, including requests to compare or describe routes, read [menu](references/menu.md). Use the request, context and short descriptions. Leave task files and alternative procedures unread until selection. Include every mandatory option, explain the recommendation and wait for one choice. Before interpreting a menu reply read [choice](references/choice.md).

Apply the chosen procedure within its authorized scope. Request any separate approval at the action that needs it.
