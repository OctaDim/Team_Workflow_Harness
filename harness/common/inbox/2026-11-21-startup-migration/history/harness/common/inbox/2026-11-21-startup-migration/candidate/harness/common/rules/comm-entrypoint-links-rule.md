# Стартовая проверка

До задачи запусти из корня проекта обычный доверенный файл напрямую (Python 3.9+):

```sh
python3 -B harness/common/checks/ensure_entrypoint_links.py
```

При утрате входа Codex или этого always loaded правила та же команда доступна для отдельного восстановления. Project требует common. При отсутствии project проверка создаёт нейтральный каркас из [project-skeleton.json](/harness/common/base/project-skeleton.json). Существующий project сохраняется побайтно. При изменении механизма проверь оба режима установки и повторный старт.

Управляемые always loaded правила и целые папки контекстных lazy скиллов с ресурсами сверяй с опубликованными каноническими источниками из соответствующих `harness/{common,project}/{rules,skills}/`. Потерянные и повреждённые рабочие копии восстанавливай только оттуда. Для защищённых входов применяй [comm-user-owned-entrypoints.md](/harness/common/rules/comm-user-owned-entrypoints.md). Человеческим пояснениям нет места в нативном каталоге always loaded правил.

До записи проверь конфликты, права, обычные пути и их предков, включая путь запуска. Для неизвестного источника, коллизии имён или дополнительного always loaded правила в `.claude/rules/` укажи путь и остановись до задачи. Сохрани файл для решения пользователя. Принятие проектного файла — через project INBOX, удаление требует явного решения.

До восстановления сообщи о предстоящей записи. Для каждого файла повторно сверь снимок, сохрани параллельную правку; заменяй атомарно. При ошибке укажи причину, сделанные и ожидающие изменения и остановись. Незавершённую публикацию связанного набора продолжай только в той же заявке. Если в контекст уже попал прежний или неверный текст, останови старт до задачи; исправленный старт проверь в новой сессии.

При диагностике открой [SKILL.md](/harness/common/skills/comm-diagnose-harness-entrypoints/SKILL.md). Используй только общую проверку; project wrapper/launcher запрещён.
