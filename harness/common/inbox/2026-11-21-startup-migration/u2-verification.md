## Воспроизведение и границы проверки

Из корня репозитория выполнить следующую команду. Сценарий создаёт новые временные каталоги и выводит их путь. Тестовые разрешения привязаны к синтетическим заявкам внутри этих каталогов.

```sh
python3 -B harness/common/inbox/2026-11-21-startup-migration/verify_u2.py
```

Для создания отдельных свежих установок доступен [prepare_u2_fixtures.py](/harness/common/inbox/2026-11-21-startup-migration/prepare_u2_fixtures.py). Для штатной проверки из корня такой установки выполнить `python3 -B harness/common/checks/ensure_entrypoint_links.py`. Перед реальным первым переключением требуется завершить ранее открытые клиентские сессии.

| Проверка | Статус и причина |
|---|---|
| Codex | Не проверено в нативной сессии. U4 проверяет стартовый контекст, чтение полного текста, нативный выбор и применение до зависимого действия. |
| Claude Code | Не проверено в нативной сессии. На U4 требуется отдельно наблюдать автоматическую загрузку и последующее чтение агентом. |
| Два режима чтения INDEX | Сравнение выбора и расхода токенов запланировано на U4. Обе карты подготовлены для одного и того же набора требований к поведению. |
| Windows | Стартовая проверка под Windows не запускалась. Текущий инструмент публикации требует POSIX. На неподдерживаемой платформе он останавливается до записи. |
| Исторические переходы | Сопоставление версий и разделов во всём рабочем дереве относится к U3. |
