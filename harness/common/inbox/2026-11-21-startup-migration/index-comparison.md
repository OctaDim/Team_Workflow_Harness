# Сравнение чтения INDEX в Codex, 2026-11-22

**Рекомендация для согласования.** Сохранить обе карты как справочники и открывать их по необходимости. В 14 сопоставимых парах это снизило суммарный расход до первого действия на 273 286 входных токенов (17,7%). В 11 парах расход снизился, в трёх вырос. Обе стратегии дали правильный предметный результат во всех 32 сеансах. Решение о режиме для Канидата INBOX остаётся за пользователем.

## Условия

Проверена редакция `eba6ba4`, SHA-256 файла AGENTS.md — `212f11dee326d906e3a00c099eab1f902b1f1a5faf75862de58e93e8b429af24`. Codex CLI 0.166.0, модель gpt-6.2-sol. В обеих установках совпадали карты и каталог из 36 контекстных lazy скиллов. Общая карта занимает 1064 байта, проектная — 1583 байта. Размер карт учитывается отдельно от расхода модели.

На каждую пару приходились два чистых сеанса с одной задачей, режимом установки и повтором. В первом повторе сначала проверялось обязательное чтение, во втором — чтение по необходимости. Различалась одна фраза в общем always loaded правиле и его установленной копии. Пары выполнялись параллельно, каждый сеанс использовал собственный профиль и копию установки. Прочитай файл [index-comparison.json](index-comparison.json) для точных формулировок, запросов, хешей, показаний счётчиков и результатов каждого сеанса.

## Получение и применение

Во всех 32 сеансах начальная трасса содержала AGENTS.md. Из 12 ожидаемых always loaded правил впервые нативно получено 0, впервые явно получено 12, полностью получено до первого действия 12, повторных полных чтений 0. Наблюдались ответы 180 и 20, выбор значения 45 из действующей спецификации и изменение timeout с 20 на 25. В восьми задачах на объяснение конфигурации контекстный lazy скилл для её изменения не загружался. Во всех восьми задачах на изменение полный SKILL.md этого скилла получен до правки.

При обязательном чтении обе карты получены в 16 из 16 сеансов, до первого действия — в 14. При чтении по необходимости обе карты получены в 3 из 16 сеансов, все три относятся к поиску спецификации. В двух случаях карты получены до поиска, в одном — вместе с его результатами. В остальных 13 сеансах полный текст карт в трассе не наблюдался.

Все восемь поисков указали на действующую спецификацию со значением 45. В шести случаях поиск шёл в проектном каталоге specs. В двух случаях Codex искал по репозиторию с исключениями для INBOX, evidence и человеческих пояснений. Чтения старой версии со значением 15 не обнаружено. В одной паре при чтении по необходимости Codex дополнительно получил контекстный lazy скилл comm-verify-project-facts. Если сравнить только 13 корректных пар с одинаковым набором полученных скиллов, расход ниже при чтении по необходимости в 11 парах.

## Входные токены

Граница — запрос модели, начинающий поиск, чтение конфигурации или другое первое действие по задаче. Для простого вопроса граница — запрос, породивший ответ. Суммировались накопительные входные токены до этой границы включительно. Вход из кэша включён, отдельные числа сохранены в JSON. Для объяснения конфигурации дополнительно проверен расход до ответа: 654 110 при обязательном чтении и 524 911 при чтении по необходимости в четырёх парах.

Медианное снижение составило 22 595,5 токена на пару. Если включить все 16 пар, обязательное чтение потребовало 1 707 508 токенов до границы, чтение по необходимости — 1 482 632. За полные сеансы, включая последующие действия, получены соответственно 2 432 300 и 2 122 875 входных токенов. Разница включает дополнительные запросы модели, поиск и повторную передачу контекста. При двух повторах эти числа описывают измеренную серию.

## Исключённые пары и границы проверки

В двух сеансах обязательного чтения при изменении конфигурации модель запросила действие до получения карт. Соответствующие пары целиком исключены из основного сравнения. В common-only, повтор 1, вызов объединил чтение обеих карт с поиском app.toml. В common+project, повтор 2, Codex запросил git status до возврата результата стартовой проверки и до получения карт. Во втором случае проверка позднее завершилась успешно. В обоих случаях полный текст всех 12 always loaded правил уже был получен.

Codex — серия завершена. Чтение по необходимости прошло наблюдаемые проверки в 16 из 16 сеансов, обязательное — в 14 из 16. Claude Code — не проверено. Межклиентское сравнение и полная приёмка harness ожидают решения. Каноническая публикация требует отдельного одобрения версии.
