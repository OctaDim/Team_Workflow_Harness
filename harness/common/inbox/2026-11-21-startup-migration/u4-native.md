# U4. Нативные клиенты и два режима чтения карт

21 ноября 2026 года. Проверены Codex CLI 0.166.0 и Claude Code 2.1.260. Рабочее дерево, личные каталоги скиллов и плагины пользователя в тестовое пространство не подключались.

## Что удалось наблюдать

| Клиент | Режим установки | Обязательное чтение двух INDEX | Чтение по необходимости |
|---|---|---|---|
| Codex | common-only | В начальном вводе полный `AGENTS.md`, 36 имён и полных описаний контекстных lazy скиллов | Те же результаты |
| Codex | common-project | В начальном вводе полный `AGENTS.md`, 36 имён и полных описаний контекстных lazy скиллов | Те же результаты |
| Claude Code | common-only | При инициализации перечислены все 36 проектных контекстных lazy скиллов | Те же результаты |
| Claude Code | common-project | При инициализации перечислены все 36 проектных контекстных lazy скиллов | Те же результаты |

Для каждой строки и режима создано независимое рабочее дерево и чистый профиль. На уровне ядра запрещено открывать IPv4/IPv6-сокеты. Учётные данные в локальных диагностических прогонах отсутствуют. В Codex использован `debug prompt-input`. Среди выведенных текстов 0 полных файлов `SKILL.md` и 0 полных текстов из 12 установленных always loaded правил. Для Claude использовано событие `system/init`. В нём также перечислены 16 встроенных имён и 0 подключённых плагинов. Это событие не содержит текстов always loaded правил и описаний из каталога. Автозагрузка полных текстов Claude в данном прогоне остаётся непроверенной. По отдельным ячейкам результаты записаны в [u4-native-local.json](/harness/common/inbox/2026-11-21-startup-migration/u4-native-local.json).

## Поведение Codex

Выполнены все 32 нативных запуска на финальной проверяемой установке. В каждом использовалась новая рабочая копия, чистый профиль с обычной авторизацией CLI и запрет доступа инструментов к закрытому профилю. Успешная проверка доступа к фиктивному закрытому маркеру предшествовала модельному запросу. Трассы с параметрами модели указывают `gpt-6.2-sol`. Исходные суммы финального проверяющего файла начинаются с `6458503dea63`, ресурса обработки заявки с `3ba315932b26`, ресурса валидации с `bf0cd000f967`. У обязательного варианта always loaded правила порядка сумма начинается с `721ce7553ee9`, у варианта по необходимости — с `dbe6f81ef453`. Полные суммы, оценки каждой сессии, шесть полей учёта чтения и счётчики приведены в [u4-native-codex.json](/harness/common/inbox/2026-11-21-startup-migration/u4-native-codex.json).

Из 28 сессий с сохранённой локальной модельной трассой в 27 получены все 12 полных текстов **одним возвратом нескольких always loaded правил**, в одной — ни одного. В 21 из 28 сессий все 12 полных текстов уже были видны до отсечки. У первых четырёх сессий сохранилась только выдача CLI. Во всех четырёх видны составные команды чтения нескольких файлов. Содержимое полного вывода оболочки и фактический ввод модели учитывались отдельно. По текущему требованию открывать каждый недостающий файл отдельным вызовом ни одна из 16 пар не подтверждает одинаково корректный старт.

Восемь изменённых контекстных lazy скиллов не прошли в этой серии индивидуальные положительные и отрицательные нативные сценарии для каждого скилла. Обработка усечённого чтения с продолжением той же версии и остановка при недоступном контекстном lazy скилле также не подтверждены этой матрицей. Статус Codex по полному V4/V5 — **не проверено** с воспроизведёнными нарушениями старта.

## Стоимость INDEX

A означает обязательное чтение, Б — чтение по необходимости. Для объяснения и простого ответа отсечка — модельный запрос, выдавший окончательный ответ. Для поиска и изменения — запрос, выдавший первое содержательное действие по теме задания. Счётчик `turn_token_usage.input_tokens` суммируется по запросам модели от начала сессии до указанной границы включительно. Токены выдачи ещё не входят во вход этого запроса. ## Claude Code

В предыдущей диагностике чистого профиля локальное событие `system/init` перечислило 36 из 36 проектных контекстных lazy скиллов. Фактический модельный запуск завершился `authentication_failed` до действий или ответа модели. Результаты каталога Claude относятся к предыдущей редакции стенда. Нативные сценарии поведения и сравнение токенов Claude на финальной редакции — **не проверено**.

## Воспроизведение

Два стенда готовит [prepare_u2_fixtures.py](/harness/common/inbox/2026-11-21-startup-migration/prepare_u2_fixtures.py). Из обоих корней требуется провести первый и повторный запуск штатной стартовой проверки. Прикладной фиктивный конфиг и два значения кэша создаёт [u4-native.py](/harness/common/inbox/2026-11-21-startup-migration/u4-native.py). Через сеть в испытании работал только Codex CLI на обособленном дереве. Архивы заявок, старые планы, handoffs, подлинные evidence, кэши и личный профиль из рабочего дерева в стенд не копируются. Для каждого варианта меняется одно предложение канонического always loaded правила и его рабочей копии. Компоненты внутри пары совпадают по остальным входным файлам.

[u4-native-matrix.py](/harness/common/inbox/2026-11-21-startup-migration/u4-native-matrix.py) без параметров печатает расписание. Для Codex `--codex-wave КАТАЛОГ --task ЗАДАНИЕ --repeat НОМЕР` запускает заданную четвёрку. Во втором повторе обратная очередность постановки вариантов; разные клетки одной волны выполняются параллельно и используют независимые профили. Способ проверки локальной инициализации поддерживает также запуск одной ячейки с `--local-only`. [u4-native-score.py](/harness/common/inbox/2026-11-21-startup-migration/u4-native-score.py) сводит ответ, изменение файла, последовательность действий, полные тексты в выданном контексте и счётчики. Для признака полного текста требуется целая текущая версия файла в выдаче; вопрос частичного текста требует отдельного сценария. Необработанные локальные трассы и профили остаются вне заявки.
