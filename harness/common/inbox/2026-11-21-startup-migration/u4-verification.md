# U4. Проверка Канидата INBOX

Редакция файлов для проверки задана в [u4-files.tsv](/harness/common/inbox/2026-11-21-startup-migration/u4-files.tsv). В ней 39 канонических файлов для добавления или замены, 41 рабочая копия и 4 снимаемых пути. На обоих стендах проверены SHA-256 всех предлагаемых версий и отсутствие снимаемых путей. Во всех подготовленных Markdown-файлах пакетов программно проверены 75 вхождений ссылок на каждую установку, включая подписи, регистр и существование цели. Согласование публикации оформляется отдельно.

## Нативный результат и обязательность INDEX

Codex CLI 0.166.0 завершил 32 сеанса по четырём одинаковым задачам в двух установках, с двумя режимами INDEX и двумя повторами. Все 32 результата по задаче совпали с ожидаемыми. В восьми запросах на правку конфигурации полный текст контекстного lazy скилла `comm-separate-application-config` получен до записи. В восьми запросах на объяснение этот скилл не открывался. Действующий источник выбран во всех восьми заданиях на поиск.

Статус Codex — не проверено: обязательный сценарий старта провален. Из 28 сеансов с записью текста, доступного модели, в 27 сразу несколько always loaded правил получены одним вызовом. В оставшемся сеансе (только common, карты по необходимости, арифметика, повтор 2) Codex передал `rg` путь `/.claude/rules` от корня файловой системы. После кода 2 он ответил на задачу. Тексты 12 ожидаемых always loaded правил не получены, успешный запуск стартовой проверки не наблюдался. Для первых четырёх сеансов доступны агрегированные результаты CLI. Отдельная проверка нативного выбора всех восьми изменённых контекстных lazy скиллов остаётся открытой. Статус Claude Code — не проверено. Итоговый статус — не проверено.

В 14 парах удалось сравнить входные токены до одной и той же содержательной границы. Чтение карт по необходимости дало меньший расход в десяти парах, больший в трёх, одинаковый в одной. Для двух оставшихся пар доступны только итоги всего сеанса. Ни одна пара не прошла согласованный порядок старта в обеих половинах. Результаты не устанавливают обязательность карт. Сначала требуется решение о коррекции точки входа и повторение эксперимента. Сведения о способах получения текста, кэше и каждом запуске приведены в [u4-native.md](/harness/common/inbox/2026-11-21-startup-migration/u4-native.md) и [u4-native-codex.json](/harness/common/inbox/2026-11-21-startup-migration/u4-native-codex.json).

## Файловые проверки

Linux, Python 3.12.3, pytest 8.4.2. Зависимости установлены с помощью uv по существующему lock-файлу. После восстановления каждой установки запущена полная коллекция из её корня.

| Режим | Команда через интерпретатор проверочного окружения | Результат |
|---|---|---|
| Только common, нейтральный project создан при первом запуске | `python harness/common/scripts/run_tests.py` | 180 тестов прошли, код 0 |
| Common и существующий project | `python -m pytest . -q --tb=line` | 180 тестов прошли, код 0 |

До исправлений штатная команда завершалась исключением `KeyError: 'sync_bootstrap'` до сбора тестов. Первый прямой запуск старой коллекции в установке U2 остановился по отсечке после девяти неуспешных тестов и трёх ошибок настройки. В Канидате INBOX штатная команда сохраняет проверку обычных путей и запускает pytest без обратной генерации. Обновлены проверки защищённых входов, нейтрального project, комплектности, уведомлений и переносимости. В диагностике повреждённого UTF-8 и JSON теперь есть точный путь. Старт сообщает о восстановлении до записи, а при ошибке перечисляет выполненные и ожидающие изменения.

Для аудитора проверены условия, наступающие в середине работы, полные и частичные чтения одной версии, повторное чтение, выбор по метаданным, явный вызов, нужное действие и остановка при ошибке чтения. Синтетический тест трассы подтверждает поведение аудитора. Нативные результаты по клиентам приведены отдельно в [u4-native.md](/harness/common/inbox/2026-11-21-startup-migration/u4-native.md).

## Восстановление и прерывание публикации

В обоих режимах воспроизведены восстановление версии 1 при наличии версии 2 в INBOX, восстановление опубликованной версии 2 после удаления тестовой заявки и сохранение сторонней версии при возобновлении. Первое переключение в отдельном стенде прошло 42 канонические операции, 41 рабочую операцию и снятие старого авторского шаблона. [verify_u2.py](/harness/common/inbox/2026-11-21-startup-migration/verify_u2.py)

Изменение отчёта, манифеста или одобренного файла до старта вызвало отказ до создания журнала. В восьми независимых стендах процесс прекращался сразу после записи проверяющего скрипта, канонического образца, удаления общего START, записи каждого из двух защищённых входов, установки контекстного lazy скилла, установки always loaded правила или снятия авторского шаблона. Во всех восьми случаях старт обнаружил незавершённую публикацию. Возобновление того же набора завершилось сверкой рабочих копий и успешной стартовой проверкой. [verify_u4_publication.py](/harness/common/inbox/2026-11-21-startup-migration/verify_u4_publication.py)

## Расход и статические проверки

Для пяти изменённых always loaded правил приведены число слов, символов Unicode и файловая оценка токенов штатной функцией `estimateTokenCount` из Plugin Eval. Это оценка прочитанного файла. Наблюдаемый расход сессии зависит также от повторных обращений и кэша.

| Always loaded правило | Слов | Символов | Оценка токенов |
|---|---:|---:|---:|
| comm-entrypoint-links-rule.md | 219 | 1945 | 487 |
| comm-human-folder-guides.md | 268 | 2269 | 568 |
| comm-instruction-order.md | 298 | 2209 | 553 |
| comm-skill-rule-ownership.md | 299 | 3208 | 802 |
| comm-user-owned-entrypoints.md | 231 | 1993 | 499 |

Все пять укладываются в 300 слов и 1000 оценочных токенов на файл. Для двух карт INDEX файловая оценка составляет 252 и 342 соответственно. Эти числа нельзя использовать как измеренную экономию при смене порядка чтения.

Восемь контекстных lazy скиллов прошли `quick_validate.py` и обработаны командами Plugin Eval `start` и `analyze` с фильтром человеческих пояснений. В исходной редакции у восьми оценка A. Для Канидата INBOX три оценки B и пять C. Во всех восьми случаях анализатор сообщает `broken-relative-links`, поскольку разрешает ссылки относительно папки скилла и не поддерживает согласованный здесь формат от корня проекта. В двух установках проверены все 20 вхождений ссылок в машинных Markdown этих восьми папок на режим. Цели доступны. Исходные оценки Plugin Eval и рекомендации сохранены в [u4-skill-checks.tsv](/harness/common/inbox/2026-11-21-startup-migration/u4-skill-checks.tsv). Формальный критерий A остаётся открытым. Общие ресурсы `comm-process-harness-inbox` сокращены с 1306 до 1180 оценочных токенов, ресурсы `comm-validate-harness-instructions` с 1405 до 1189. Рекомендации по объёму выше целевого ориентира 1000 сохраняются.
