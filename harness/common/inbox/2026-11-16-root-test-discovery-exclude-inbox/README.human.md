# Общий прогон тестов без автоматического запуска inbox

Здесь находится заявка на рекурсивный запуск тестов от корня проекта с двумя
исключениями inbox. В request.md записаны согласованные требования и будущие
проверки, а в candidate/ — непроверенные варианты существующих процедур.

Например, обычный прогон должен находить тесты приложения вне harness, а тесты
выбранного кандидата из inbox можно запускать отдельной целевой командой.
Создание этой папки не означает выполнения или публикации изменений.
