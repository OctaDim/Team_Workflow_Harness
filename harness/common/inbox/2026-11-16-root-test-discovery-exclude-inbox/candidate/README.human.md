# Непроверенный кандидат: candidate

Папка candidate содержит часть полного кандидата существующей процедуры.
Например, ресурс references/testing.md описывает общий и целевой запуск тестов,
а references/workflow.md сохраняет границы разрешений при обработке заявок.
Это подготовка для рассмотрения; действующий harness эта папка не заменяет.
