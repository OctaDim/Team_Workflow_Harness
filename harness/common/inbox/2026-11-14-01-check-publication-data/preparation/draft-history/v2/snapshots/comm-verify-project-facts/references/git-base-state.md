# Git base state

Determine the project's integration branch and intended remote, not assumed
origin/main. Ambiguity requires the user's answer before dependent actions.
Obtain fresh remote state within authority; verify the fetched ref and capture
target/working SHAs. Offline/stale local refs need an explicit user decision.
Check at independent task start, deferred-task resumption, final verification
and immediately before integration. Before resumed implementation, incorporate
missing integration changes; an agreed feature dependency does not waive this.
For target advancement assess impact and required updates/checks. Record
checked SHAs: no promise of perpetual latest code. Inspection does not require
changing the local branch; PR read-only limits remain.
