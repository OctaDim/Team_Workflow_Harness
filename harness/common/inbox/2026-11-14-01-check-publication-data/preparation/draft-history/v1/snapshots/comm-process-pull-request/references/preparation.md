# Prepare the PR

Verify exact repository/head/base and intended commit scope; resolve ambiguity
with the user. The request permits necessary ordinary publication of that branch
to the agreed remote, not a new fork, forced rewrite or local branch changes.
Use the project's template. Summarize problem/result, actual checks with revision/
environment and evidence links, plus failed/unrun checks and limits with reasons.
Use application/harness report owners; keep full evidence separately.
Update the summary when scope/version changes. Check the actually saved text;
neither CLI nor template automatically supplies truthful verification content.
