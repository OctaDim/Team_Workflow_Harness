# Platform conditions

On the same host, prefer a suitable native transfer when retained identity,
metadata/settings and permissions meet the goal. For a distinct copy or another
host compare import/mirror and explicit metadata/integration migration.
Check current host documentation and observed configuration; copying Git refs
alone does not prove whole-project migration.
For GitHub, old-location reuse can permanently remove transfer redirects.
Validate redirect/name implications before changes; do not export one project's
origin, organization, runner names, token behavior or historical pricing as defaults.
An error does not authorize another channel or broader access.
