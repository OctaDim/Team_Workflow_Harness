# Считать явный вызов скилла или плагина выбором маршрута

Создана 20 ноября 2026 года при разборе [заявки о старте Codex](../2026-11-19-codex-explicit-skill-startup/request.md). При одинаковом поручении применить скилл Codex иногда показывал меню и ждал выбора. [Соседняя заявка](../2026-11-20-explicit-skill-after-index/request.md) касается порядка чтения файла. Здесь требуется определить, когда после обязательного старта можно сразу приступить к задаче.

## Предложение пользователя

> Явное поручение применить конкретный скилл или плагин к конкретной задаче считается выбором маршрута и позволяет начать без меню. Меню показывай, когда пользователь просит сравнить маршруты или его запрос допускает несколько существенно разных способов выполнения. Для действий, требующих отдельного согласия, сохраняй соответствующий шаг согласования.

В [полном кандидате правила](comm-confirm-development-workflow.md) указаны три формы явного поручения. Для отдельной операции Codex выбирает простой маршрут и применяет названный скилл или плагин. Выбранный полный процесс или его однозначная точка входа запускают соответствующий процесс. Вопрос «Какой маршрут выбрать?» и существенную неоднозначность определяют по тексту задачи и уже доступному контексту. До выбора не открывают плагины, правила и скиллы альтернативных маршрутов для их анализа.

При выполнении согласовать это поведение с [процедурой выбора](../../skills/comm-select-development-workflow/SKILL.md), в том числе с её указанием оставлять скиллы Superpowers и CE непрочитанными при простом маршруте. Явно названный скилл отдельной операции должен применяться и в этом случае.

## Приёмка

1. По очереди передать «Примени `$superpowers:systematic-debugging` к сбою в CI», «`$superpowers:systematic-debugging` Исправь сбой в CI» и «`/superpowers:systematic-debugging` Исправь сбой в CI». После обязательного старта в каждом случае Codex начинает диагностику по названному скиллу, например запрашивает журнал первого упавшего шага, если журнал не приложен. Меню и выбор полного процесса для этого не нужны.
2. Дать конкретную задачу с явным поручением применить плагин для одной однозначной операции. Codex приступает к этой операции простым маршрутом.
3. Проверить два запроса на полный процесс. В одном пользователь прямо выбирает процесс, в другом называет его однозначную точку входа. В обоих случаях Codex следует этапам выбранного процесса.
4. Передать «Какой маршрут выбрать для расследования сбоя в CI?», затем в отдельной сессии дать задачу, формулировка которой оставляет открытыми несколько существенно разных маршрутов. В обоих случаях Codex показывает меню и ждёт выбора. По трассе проверить, что для решения о меню агент не открывал тела альтернативных маршрутов, их плагинов, правил и скиллов.
5. Дать явное поручение со скиллом, в котором конкретное действие требует отдельного согласия. Codex принимает выбор маршрута и запрашивает предусмотренное согласие перед этим действием.
