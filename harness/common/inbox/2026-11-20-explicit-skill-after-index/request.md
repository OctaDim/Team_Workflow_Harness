# Явный вызов скилла в Codex при существующем AGENTS.md

Создана 20 ноября 2026 года после разбора порядка чтения явно запрошенного скилла. Дополняет [заявку о старте Codex при явном вызове](../2026-11-19-codex-explicit-skill-startup/request.md) с учётом [правила об однократном чтении](../2026-11-20-skill-read-once-across-rule-and-index/request.md).

## Исправление

Существующий AGENTS.md подключает правила до обоих INDEX. Правило порядка чтения задаёт последовательность индексов, но фраза «Для задачи загрузи только нужные скиллы» оставляет открытым вопрос, когда и как прочитать явно запрошенный SKILL.md.

В [полном кандидате правила](comm-instruction-order.md) уточнён шаг после чтения INDEX common и INDEX project. Если Codex уже прочитал в этой сессии полный актуальный SKILL.md запрошенного владельца, он применяет этот текст. Иначе до применения скилла Codex отдельным вызовом читает файл целиком или дочитывает недостающие фрагменты той же версии. Изменение относится к каноническому правилу и его установленной копии.

## Приёмка

Провести два независимых запуска Codex с копией существующего AGENTS.md в каждом поддерживаемом режиме установки (common-only и common+project). В каждом запросе явно назвать скилл и дать задачу с наблюдаемым шагом его процедуры. По трассе сверить владельца, версию, содержимое результатов чтения, порядок событий и применение скилла.

1. **Первое полное чтение.** Выбрать скилл, который стартовые правила не требуют открывать заранее. В трассе последовательно видны полное чтение INDEX common и INDEX project, затем отдельный вызов чтения нужного SKILL.md. До применения скилла получен весь текст. При обрезанном выводе недостающие фрагменты дочитаны. Имя в каталоге или успешный код выхода сами по себе не подтверждают полноту.
2. **Повторное использование.** Выбрать явно запрошенный скилл, который до индексов требуется прочитать по применимой ссылке из правила. В трассе видны полное раннее чтение нужной версии, оба INDEX в установленном порядке и применение процедуры после них. За весь запуск зафиксировано ровно одно полное чтение SKILL.md, после INDEX повторного чтения файла нет.
