# Группа 8. Безопасный повтор внешних операций

Дата возникновения потребности и создания заявки — 2026-11-19. Порядок в группе — 1 из 2.

При разборе группы 8 возник вопрос о потере ответа после отправки документа. Сервис мог уже выполнить операцию. Повтор способен создать дубль, а вложенные попытки клиента и SDK могут выйти за дедлайн вызывающего кода.

## Согласованный результат

1. Сервис мог выполнить операцию до потери ответа. Сохранить неизвестный исход и сверить его по устойчивому идентификатору. Если достоверного ответа нет, исход остаётся неизвестным. Автоматический повтор допустим в пределах гарантий идемпотентности API или после достоверного подтверждения, что первая попытка не выполнилась.
2. При проектировании API определить ошибки и условия безопасного повтора. Для клиента различить тайм-аут, сетевой сбой, отмену и ошибки API. Для каждого исхода определить результат для вызывающего кода и допустимость повтора. Задать тайм-аут отдельного запроса, общий дедлайн с учётом всех попыток и пауз, включая встроенные повторы SDK, лимит попыток и результат исчерпания бюджета. Для разрешённых повторов по умолчанию применять растущую задержку со случайным разбросом. Учитывать указанное сервисом время следующей попытки. При выходе ожидания за дедлайн завершить операцию без нового запроса.

## Критерии приёмки

- Сервис выполнил операцию, ответ потерялся, дальнейшая обработка не создала дубль.
- Тесты с управляемым временем проверяют тайм-аут отдельного запроса, восстановление после временного сбоя, остановку при отмене или неповторяемой ошибке, исчерпание бюджета и отсутствие нового запроса, если рекомендованная сервисом задержка выходит за дедлайн.

## Форма инструкции

Один скилл для проектирования API и клиентов. Порядок выбора повтора целиком зависит от контракта внешней операции. Контекст задачи позволяет загрузить скилл по описанию. Оснований для постоянно загружаемого правила, отдельно или в паре со скиллом, не выявлено. Проверка возможна на границе клиента и сервиса независимо от фонового планировщика. Постраничная сверка остаётся примером для проектов с соответствующим API.
