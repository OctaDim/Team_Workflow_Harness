## Объём проверок

- `quick_validate.py` прошёл. Проверены относительные ссылки, соответствие
  базовой версии и целостность обязательных ресурсов.
- `plugin-eval start`, `analyze` и `compare` через фильтр человеческих
  пояснений подтвердили оценку A (100) для обеих версий. Ошибок,
  предупреждений и обязательных исправлений нет. Сведения о покрытии
  исходного кода к Markdown-скиллу не применимы.
- Статическая оценка объёма в токенах — 44 для метаданных, 396 для
  `SKILL.md` (178 слов) и 501 для обоих ресурсов. До изменения ресурсы
  составляли 436 токенов. Оценка 501 укладывается в диапазон анализатора
  до 520 токенов. Стартовые правила и метаданные совпали с исходными.
- В прогонах с коммитом по журналам подтверждено чтение основного скилла,
  обоих ресурсов, `comm-check-publication-data` и `ce-commit` из
  Compound Engineering 3.38.2. В сценариях только на чтение ни один из этих
  текстов не загружался. Метаданные проверены отдельно через `skills/list`.
- В четырёх временных установках исходной версии и кандидата по два раза
  выполнен `python3 -B harness/common/checks/ensure_entrypoint_links.py`.
  В common-only создан нейтральный project. В common+project проверено
  сохранение существующих файлов. Повторный старт не изменил входы.
  Отдельно получен отказ при отсутствии common и при отсутствии обязательного
  ресурса. Каноническая установочная структура не редактировалась.
- Первые попытки выполнения в режиме `workspace-write` подтвердили чтение
  инструкций и выявили запрет записи в `.git`. Их черновики и отсутствие
  коммитов не засчитаны. Успешно сохранённые сообщения проверены только в
  повторных прогонах с правом записи во временные Git-репозитории.

Нативные команды — `codex -a never exec --ephemeral --json -C <fixture>`
с `--sandbox danger-full-access` для коммитов и `--sandbox workspace-write`
для задач только на чтение. Сохранённый результат проверен через
`git show -s --format=%B`, список файлов коммита и состояние рабочего дерева.
