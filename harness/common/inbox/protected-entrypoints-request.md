# Проверка AGENTS.md и CLAUDE.md: подтверждённая заявка

Дата: 2026-10-05. Статус: уточнённое требование реализовано в common. Project-only и нативная приёмка ещё не завершены.

## Контекст и уточнение

Статичные входы не должны становиться памятью сессий. Пользователь запретил прямые изменения AGENTS.md и CLAUDE.md агентам и пользователям и оставил узкое исключение для согласованного создания и восстановления стартовых ссылок.

Первоначально выбранную защиту Git hook пользователь отменил: harness должен работать без дополнительных индивидуальных настроек машины. Итоговую формулировку пользователь отдельно подтвердил:

> Прямое редактирование запрещено договорённостью harness, но технически не заблокировано.

## Требуемый и реализованный результат

- Прямые изменения предлагаются через inbox соответствующего пакета; применение — после согласования в отдельной обработке. Заявка сама по себе не разрешает правку.
- Проверка AGENTS.md/CLAUDE.md выводит предупреждение о договорённости, отсутствии технической блокировки и маршруте через `harness/<пакет>/inbox/`.
- Перед записью восстановленных ссылок выводится: «Стартовые ссылки повреждены и будут автоматически восстановлены.» При целых ссылках нет ложного сообщения о повреждении.
- Другие настройки и лишний текст сохраняются. Предупреждение не блокирует редактирование, задачу или коммит.
- Проверка не устанавливает hooks, не меняет Git/машинные настройки и не требует Git или регистрации версии входов. Нужен Python 3.9+.
- Уже имеющаяся история Git может использоваться для сравнения. Без неё прошлое произвольного текста AGENTS.md не проверено, а не объявлено неизменным.
- Сообщения не записываются в статичные входы. Состояние задач и память остаются в harness.
