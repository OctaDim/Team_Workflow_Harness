# Кандидат скилла

Папка comm-bound-search-output содержит полное предлагаемое содержимое
будущего скилла с тем же именем.
Например, проверка должна показать, что обычная просьба найти материал
вызывает загрузку скилла до первого потенциально большого результата.
Кандидат пока не установлен и не проверен в нативных агентах.
