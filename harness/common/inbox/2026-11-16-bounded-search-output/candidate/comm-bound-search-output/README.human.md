# Предлагаемый скилл ограничения вывода

Эта папка содержит полный кандидат скилла comm-bound-search-output.
Например, при слишком большом результате агент должен вернуть ограниченную
выборку с отметкой о неполноте и продолжить более узким запросом.
Наличие папки не доказывает обнаружение скилла или соблюдение ограничения.
