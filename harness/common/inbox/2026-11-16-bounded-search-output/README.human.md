# Ограничение вывода поиска

Здесь находится заявка на скилл, уменьшающий объём результатов поиска,
попадающих в контекст агента, и полный непроверенный кандидат.
Например, вместо тысяч найденных строк агент должен получить сводку
и небольшой фрагмент с явным признаком неполноты.
Создание заявки не означает, что скилл установлен или доказал свою работу.
