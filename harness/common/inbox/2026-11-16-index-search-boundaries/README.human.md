# Заявка о границах поиска

Здесь находится предложение уточнить поиск в общем INDEX: request.md описывает
причину, границы и будущую приёмку, candidate-INDEX.md показывает полный результат.
Например, при работе над актуальным кандидатом можно открыть нужное свидетельство,
а историческую копию нельзя считать действующей инструкцией только по её имени.
Создание заявки не означает внесения изменения в действующий INDEX.
