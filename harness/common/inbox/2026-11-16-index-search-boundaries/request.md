не дублировать его. Остальной текст INDEX сохранить.

```markdown
- Исключай `README.human.md` на любой глубине.
- В inbox сначала установи статус и применимость заявки.
  Исторические before/candidate-копии не определяют текущие требования.
- Evidence и исторические снимки открывай для конкретного
  результата, расхождения или вопроса об истории.

Ограничение исторических копий не запрещает работу с выбранным актуальным
кандидатом, проверку его требований и обращение к свидетельствам, необходимым
для текущей задачи.
```
