# Область и сценарии comm-update-git-branch

Дата создания: 2026-11-14.

Это план будущего исполнения, не журнал прошедших проверок.

- **2. Свежесть основы:** Определять remote/интеграционную ветку по проекту; неоднозначность требует ответа. Новая независимая задача — от свежего удалённого SHA. При возобновлении и зависимости проверить расхождение и актуализировать основу до реализации. Сравнить новую ветку с контролируемым переносом и актуализацию существующей. Проверить совместимость, повторно проверить цель перед интеграцией, учитывать гонку и записывать SHA. Недоступность remote не разрешает молчаливую подмену локальной ссылкой.
- **4. Смысл разрешения конфликтов:** Сохранить действующие согласованные контракты обеих сторон, не восстанавливая отменённое. Не выбирать сторону массово. Неясный смысл/защищённая область требует решения. Проверить переименования/вызовы, регенерацию по согласованным входам, незаметные версии/форматы/cache/build/API, фактическую резолюцию и проверки объединённого влияния через существующих владельцев.

## Сценарии

- Методы A/B, зависимости и опубликованная история без универсального rebase/merge.
- Комбинированная резолюция, переименованный API и старые callers.
- Generated/lock из согласованных входов; silent version/cache/build conflicts.
- Новая версия сбрасывает старое green; проверки объединённых контрактов.
- Неясное намерение/SQL approval/PR read only блокируют зависимую мутацию.
