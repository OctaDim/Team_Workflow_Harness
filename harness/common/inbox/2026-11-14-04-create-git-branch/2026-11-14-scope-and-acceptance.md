# Область и сценарии comm-create-git-branch

Дата создания: 2026-11-14.

Это план будущего исполнения, не журнал прошедших проверок.

- **2. Свежесть основы:** Определять remote/интеграционную ветку по проекту; неоднозначность требует ответа. Новая независимая задача — от свежего удалённого SHA. При возобновлении и зависимости проверить расхождение и актуализировать основу до реализации. Сравнить новую ветку с контролируемым переносом и актуализацию существующей. Проверить совместимость, повторно проверить цель перед интеграцией, учитывать гонку и записывать SHA. Недоступность remote не разрешает молчаливую подмену локальной ссылкой.
- **3. Имя ветки:** Формат <git-user>/<short-meaningful-name>; префикс — local part Git-почты до @. Не использовать user.name как логин. Неоднозначность/недопустимый префикс требует короткого префикса от пользователя. Содержательный результат, не автоматическое название тикета; common не требует Linear/тикет/ID. Пример octadim/add-agent-use-some-tool. Проверить literal через check-ref-format, локальные/удалённые совпадения, предложить альтернативу и дождаться выбора; без автосуффикса и перезаписи.

## Сценарии

- Свежая именованная remote-интеграционная основа вместо текущего feature HEAD.
- Префикс из effective Git email; user.name/неоднозначность/недопустимость.
- Имена local/remote заняты, гонка создания; без суффикса/перезаписи.
- Нет Linear/тикета; содержательный результат вместо копии ticket title.
- Host не создал ветку: не сообщать успех; сохранить исходный staging.
