# Область и сценарии comm-commit-task-stages

Дата создания: 2026-11-14.

Это план будущего исполнения, не журнал прошедших проверок.

- **1. Сохранность Git-работы:** Определить repo/worktree/HEAD, staged/unstaged/untracked и владение. Сохранить чужие правки и staging, включая общий файл. Не очищать дерево stash/commit/reset/clean/переносом чужой работы. Координировать активного писателя; worktree — опция с общими refs/config. Неясность блокирует зависимую мутацию до ответа.
- **9. Текст как данные:** Структурированный параметр инструмента/API без построения shell-команды; для CLI — безопасно созданный файл и body-file/commit -F по процедуре владельца. Защитить заголовки/пути/все shell-конструкции; JSON внутри shell не экранирование. Сохранить смысл Markdown и проверить фактически сохранённый текст. Чтение общего ресурса в PR не вызывает коммит.

## Сценарии

- Чужие staged и unstaged фрагменты в том же файле сохраняются.
- Активный writer, неизвестное владение, общие refs/config worktree.
- Бэктики, shell substitution, кавычки, Unicode/newlines сохраняются как данные.
- Границы коммитов и ce-commit неизменны; PR читает ресурс без коммита.
- Обычный ответ/маленькая правка не создают отдельный commit boundary.
