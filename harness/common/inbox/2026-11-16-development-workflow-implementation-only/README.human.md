# Выбор маршрута перед реализацией

Здесь находится заявка на уточнение границ обязательного выбора маршрута.
Например, объяснение правила должно проходить сразу, а перед изменением кода
без заранее выбранного маршрута агент должен показать меню и дождаться выбора.
Требования и фактический статус находятся в request.md. Создание этой папки
не означает исполнения заявки или публикации изменений.
