# Синхронизация шаблонов начальной установки

В request.md описаны исправление шаблона AGENTS.md, проверка старта в двух режимах и автоматическое обновление шаблонов. Например, если меняется порядок чтения правил, новая установка должна получить актуальные указания, а пользователь — сообщение о том, какой шаблон обновился.
