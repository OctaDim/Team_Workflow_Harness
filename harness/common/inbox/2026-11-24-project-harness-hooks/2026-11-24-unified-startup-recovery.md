# U4. Единая сверка SHA-256 и автоматическое восстановление

Дата — 2026-11-24 (Europe/Minsk). Дерево Канидата INBOX — `281456162d0f4b615c4e986f8b1182850339f6bc`. SHA-256 скрипта — `c1dc6fd11543293fc2621c2031b75b2cb686bf7235aaccbf91597696b7f84348`.

Синхронный UserPromptSubmit использует единую сверку без записи. Команда --check-startup выводит только OK при совпадении или относительные пути и их состояния при расхождении. Команда --restore-startup автоматически исправляет управляемые копии из опубликованного канона и удаляет лишние файлы после проверки их резервных байтов. Если безопасное чтение или резервное копирование невозможно, рабочие файлы сохраняются. После записи повторяется вся сверка и требуется свежий сеанс.

Резервный коммит хранится под отдельной ссылкой refs/harness/backups/<Git ID>. Временный Git-индекс содержит только исходное дерево и затронутые пути. Текущая ветка и пользовательский индекс сохраняются. Триггер выдаёт полный Git ID и пути. Возврат сохранённых файлов или публикация новой версии канона выполняются через отдельную INBOX-заявку пользователя вне работы триггера.

## Файловые проверки

В каждом изолированном режиме прошло 209 штатных тестов. В отдельных копиях подтверждены отсутствие записи при OK, восстановление отдельно удалённых AGENTS.md, CLAUDE.md и рабочего always loaded правила, замена пустого отличающегося AGENTS.md, резервное копирование непустого CLAUDE.md и изменённого always loaded правила. В смешанном сценарии один проход вернул четыре состояния, включая реально недоступную для чтения копию. Отдельно подтверждены остановка при ошибке создания коммита и при подмене результата проверки резервных байтов, сохранность всех затронутых рабочих файлов и автоматическое удаление лишнего после успешной проверки.

## Нативные прогоны

Codex CLI 0.166.0 и Claude Code 2.1.260, свежие профили в обоих режимах. Проектные настройки и синхронный адаптер UserPromptSubmit добавлены только в стенды. Тесты не утверждают, что установка штатных триггеров или загрузка контекста всей миграции уже приняты.
