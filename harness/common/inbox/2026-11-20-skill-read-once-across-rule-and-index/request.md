# Проверять однократное чтение одного скилла по ссылкам из правила и INDEX

Дата возникновения и создания — 2026-11-20. Пакет — common.

При обсуждении [заявки о чтении скиллов по ссылкам из правил](../2026-11-19-rule-linked-skill-reading/request.md) выявлен отдельный случай. Её критерии охватывают ссылки из двух правил и массовое перечитывание после INDEX. Требуется обнаруживать также одиночный повтор, когда короткое правило и INDEX указывают на один и тот же скилл.

## Критерий приёмки

В рамках одного запуска, если короткое правило и INDEX ссылаются на один и тот же скилл и агенту требуется его прочитать, полный актуальный текст скилла читается один раз. Проверка трассы должна охватывать чтения и до, и после INDEX. Повторное полное чтение неизменившегося скилла — ошибка, даже если все остальные скиллы прочитаны по одному разу. При таком повторе проверка сообщает об ошибке и указывает скилл. Агент показывает ошибку пользователю, запрашивает его решение о дальнейших действиях и ждёт ответа. Продолжение допускается только по явному решению пользователя.

| Трасса | Ожидаемый результат |
| --- | --- |
| Условие ссылки в правиле выполнено. Агент полностью прочитал скилл, затем встретил ссылку на тот же скилл в INDEX и использовал уже полученный текст | Успех. Две ссылки, одно полное чтение |
| Та же трасса, но после INDEX агент ещё раз полностью прочитал тот же неизменившийся скилл | Ошибка повторного полного чтения. Проверка указывает скилл. Агент сообщает пользователю о повторе, запрашивает решение и приостанавливает задачу до ответа |
| До INDEX агент увидел только ссылку. Полный текст впервые прочитан после INDEX, когда скилл понадобился | Успех. Появление имени или ссылки не засчитывается как чтение |
| До INDEX получен только фрагмент, после INDEX дочитан остаток той же версии | Успех. Подтверждено одно полное чтение |
| После первого полного чтения файл изменился, и после INDEX агент прочитал актуальную версию | Чтение новой версии допустимо. Ошибка повтора применяется к неизменившемуся тексту |

При выполнении добавить парные положительную и отрицательную регрессии для [проверки трассы](../../checks/check_human_guide_search.py) в [набор тестов чтения](../../testing/tests/test_human_guide_reader.py). В этих двух трассах использовать один и тот же скилл и одну версию. Единственное различие — дополнительное полное чтение после INDEX.
