# Проверка правила о ясных и коротких сообщениях

Дата проверки: 2026-11-24. [Кандидат](comm-clear-agent-messages.md), SHA-256 `6f1ae43c97fd06589cebda5d37a46d2b60d656aceb8dc6f4cc9d5204519990a9`.

Кандидат действует на обычные ответы, промежуточные обновления и сообщения при блокере. Короткое стартовое правило покрывает сообщения, для которых контекстный скилл не вызывается. Редакция уточняет, что вопрос нужен, если от решения пользователя зависит следующий шаг, и задаёт ориентир для обычного сообщения в 1–3 предложения с возможностью дать необходимые подробности.

## Размер и установка

- 109 слов, 785 символов Unicode, статическая оценка plugin-eval 0.1.2 — 197 токенов. Диапазон до 150 слов и цель до 1000 токенов соблюдены. Оценка каталога с одним файлом — A, 100/100, ошибок и предупреждений нет. Предыдущая редакция кандидата — 103 слова, 754 символа и 189 токенов. В базовой версии правило отсутствовало.
- Временные версии `common-only` и `common+project` дважды прошли `python3 -B harness/common/checks/ensure_entrypoint_links.py`. В первом режиме создан нейтральный `project`, во втором сохранён существующий. Повторный запуск сохранил содержимое каталогов проекта.
- `test_rule_copies.py` через uv с `requirements.lock` — 8/8 на двух временных установках. Проверены действующие копии, отсутствие common и расхождения в каждом режиме.

## Поведение

Codex CLI 0.166.0, `gpt-6.2-sol`, `low`. Свежий сеанс для каждого сценария и режима. Запуск: `codex exec --skip-git-repo-check --ephemeral --ignore-user-config -s read-only -c 'model_reasoning_effort="low"' -C <копия> --color never --json <сценарий>`. Сценарии используют синтетические данные.

| Сценарий | `common-only` | `common+project` |
|---|---|---|
| Обычный ответ о выгрузке | Частичный результат в начале, указаны 18 из 20 и причина двух отказов. Три предложения | Тот же результат и три предложения |
| Статус U4 | Различены согласование, стенд и открытая проверка интеграции. Переход к U5 привязан к её подтверждению | Тот же результат |
| Промежуточное обновление U4 | Между чтениями двух файлов объяснено, почему остаётся работа с триггерами и что проверяется дальше. Три предложения | Тот же результат и три предложения |
| Блокер выпуска | Найдена запись о согласованном каталоге. Задан один вопрос о CSV или JSON. Выгрузка не запускалась | Тот же результат. В одном сеансе нарушен стартовый порядок |
| Запрошенные подробности | Обе команды и смысл каждой приведены, команды не запускались | Тот же результат |

В ранних прогонах блокера фикстура называла `reports/` доступным, хотя каталог отсутствовал. В следующих прогонах путь существовал, но согласование отсутствовало в постоянных решениях. В контрольном сценарии с каталогом и записью оба режима задали один вопрос о формате. Базовая версия с той же полной фикстурой также задала этот вопрос, поэтому для него сравнительное преимущество текста не установлено. В ответах о блокере встречалось до пяти предложений, включая подтверждение согласованного пути и отсутствия запуска. Обычные ответы и целевые промежуточные обновления уложились в три.

В Codex первое сообщение о начале стартовой проверки может предшествовать явному чтению `.claude/rules`. Оценка поведения текста относится к сообщениям после загрузки правила. Чтение правила до первого сообщения не заявляется.

В одном сеансе `common+project` повторно полностью прочитаны `.claude/rules/comm-confirm-development-workflow.md`, `.claude/rules/comm-dependencies-through-uv.md`, `.claude/rules/comm-entrypoint-links-rule.md` и `.claude/rules/comm-instruction-order.md`. Сеанс продолжился и задал вопрос о формате. Успех ответа сохраняется как отдельный результат. Полная проверка стартового порядка в этом режиме не пройдена.


Повтор в свежей копии `common+project` подтвердил одно чтение каждого правила и тот же вопрос о формате без повторного согласования каталога. Первое нарушение сохранено в результатах.

**Статусы проверки.** Codex `common-only` — пройдено по целевым сообщениям после загрузки правила. Codex `common+project` — целевые сообщения проверены, полная проверка стартового порядка не пройдена из-за наблюдавшегося повторного чтения. Claude Code в обоих режимах — не проверено. Итог — не проверено.

В каждом прогоне наблюдалось чтение правила из установленной копии. Нагрузка на старт по оценке файла увеличивается на 197 токенов. Фактическая проверка чтения ниже отражает все правила, загруженные по стартовому порядку. Временные JSONL сохраняют сообщения, чтения последующих зависимостей и расход сеансов целиком.
