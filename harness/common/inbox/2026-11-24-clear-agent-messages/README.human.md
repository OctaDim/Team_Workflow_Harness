# Ясные и короткие сообщения агента

Здесь собраны предложение для общего harness, критерии приёмки и полный текст Канидата INBOX. Например, в сообщении о ходе работы агент указывает, что уже согласовано и какая проверка осталась.

Откройте [request.md](request.md), чтобы посмотреть состояние заявки, и [comm-clear-agent-messages.md](comm-clear-agent-messages.md), чтобы прочитать предложенный текст.
