# Проверка коммита при завершении задачи

Здесь лежат заявка, порядок её будущей проверки и черновик короткого правила.

Например, после публикации и проверки инструкции агент перед следующей заявкой
обращается к существующему скиллу коммитов. Если есть завершённый результат и
запись в Git разрешена, агент фиксирует изменения и сообщает хеш коммита.
