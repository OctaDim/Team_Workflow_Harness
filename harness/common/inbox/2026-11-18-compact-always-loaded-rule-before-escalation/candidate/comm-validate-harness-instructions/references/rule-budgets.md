# Always-loaded rule budgets

For each new/edited always-loaded rule report path/version, W=len(text.split()),
word-band, C=Unicode characters and stock plugin-eval static tokens T from the
complete unnormalized UTF-8 text. Obtain T from that file's budget component
through authorized human-filtered evaluation, not directory total or a custom
counter. Record tool/version/method; missing estimates stay unverified, not zero.
Stock `ceil(text.length/4)` counts UTF-16 units; disclose differences from C.
Preserve analyzer findings/bands/thresholds; estimates are not usage or cost.

W≤150 good; 151–300 moderate; 301–500 heavy-warn; >500 excessive-fail.
Heavy-warn recommends coherent splitting; excessive-fail strongly recommends it.
Target T≤1000; >1000 warns/recommends remediation; >1200 strongly recommends.
Evaluate both axes independently. If W>300 or T>1000, first try to shorten the
candidate within authorized scope. Preserve triggers, obligations, exceptions
and stop points, including what must apply before procedure selection. For an
amendment, preserve existing behavior except for the intended changes.
Re-measure both axes and repeat mandatory checks on the revised version.
A reduction resolves the excess when both budgets pass and preservation of
behavior is verified. If excess remains or no behavior-preserving reduction
can be verified, report before/after values and gaps, show options, and wait
for an explicit decision before dependent work. Bind any budget exception to
the current rule/version and the exceeded measures. Refusal, ambiguity,
silence or generic prior permission keeps it stopped. Preserve
measurements/bands and other gates. Shortening/splitting preserves obligations
and ownership; measure combined reading, since splitting alone proves no saving.
Re-evaluate edits. No whole-startup cap or publication waiver.
