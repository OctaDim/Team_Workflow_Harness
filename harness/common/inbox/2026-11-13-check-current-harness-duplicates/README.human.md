# Проверка дублей по актуальным источникам

Здесь находится заявка на самостоятельный lazy-скилл common harness и его полный
предварительный кандидат. Пример: перед предложением нового правила проверить
действующих владельцев и актуальные открытые заявки, не перечитывая архив.
Создание заявки не означает, что скилл установлен или проверен.
