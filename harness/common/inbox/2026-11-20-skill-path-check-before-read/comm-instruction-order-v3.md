# Обязательный порядок инструкций harness

После стартовой команды прочитай START common, затем project и указанные ими правила. Получив полный актуальный текст правила, сразу перейди к скиллу по безусловной ссылке, по условной — при наступлении условия. Читай отдельным вызовом даже до перечисления, независимо от длины правила. Соблюдай запреты ранней загрузки. Чтение не разрешает действия.

В Codex выдели внешний вызов инструмента только для требуемой проверки файла SKILL.md и компонентов пути. Заверши вызов, дождись ответа и оцени его. При отказе или неопределённости остановись до чтения. При подтверждении следующим внешним вызовом прочитай только проверенный файл или недостающий фрагмент той же версии. Не совмещай проверку с поиском или чтением даже последовательными await внутри вызова.

Отдельно перечисли все Markdown-файлы установленной .claude/rules/ рекурсивно, кроме README.human.md. Для чтений через START подтверди установленный путь и содержимое. Остальные правила читай по одному с переходами до следующего. Дочитывай фрагменты той же версии. При изменении или неизвестной актуальности читай текущую версию. Сверь полное чтение каждого пути списка.

До добавления безусловной ссылки или снятия условия назови файл и правку, запроси отдельное подтверждение. Дождись явного согласия без записи. Исходное поручение не заменяет ответ. Чтение согласованной ссылки повторного подтверждения не требует.

После сверки прочитай INDEX common, затем project. Применяй скилл по полному актуальному тексту владельца; явно вызванный в Codex — после обоих INDEX. Уже полученный в сессии текст, включая раннее чтение и подстановку, используй без открытия, сравнения или хеширования идентичных копий.

Загружай только нужные скиллы. Перечитав неизменный скилл целиком, сообщи ошибку и путь, запроси решение и жди ответа. Изменённую версию прочитай. Соблюдай правила и разрешения.

В списках ставь START перед INDEX, правила и их каталоги перед скиллами и их каталогами. В стартовых списках AGENTS.md помещай правила между START и INDEX. Изменив генератор, проверь создание, восстановление и повторный старт входов в common-only и common+project. Сохраняй пользовательские настройки. Переупорядочение защищённых входов проходит через согласованный inbox.
