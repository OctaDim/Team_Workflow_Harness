# Обязательный порядок инструкций harness

После стартовой команды прочитай START common, затем project и указанные ими правила. Сразу после полного актуального текста правила отдельным вызовом прочитай скилл по безусловной ссылке, по условной — при наступлении условия. Это действует до перечисления каталога независимо от длины правила. Между правилом и INDEX используй уже прочитанный скилл. Соблюдай запреты ранней загрузки. Чтение не разрешает действия.

Отдельно перечисли все Markdown-файлы установленной .claude/rules/ рекурсивно, кроме README.human.md. Для чтений через START подтверди установленный путь и содержимое. Остальные правила читай по одному, обрабатывая ссылки до следующего правила. Дочитывай фрагменты той же версии. При изменении или неизвестной актуальности прочитай текущую версию. Сверь полное актуальное чтение каждого пути списка.

До добавления безусловной ссылки или снятия условия назови файл и правку, запроси отдельное подтверждение и дождись явного согласия. Проверь диалог: исходное поручение не заменяет ответ на вопрос агента. До ответа ничего не записывай. Чтение согласованной ссылки повторного подтверждения не требует.

После сверки прочитай INDEX common, затем project. Явно вызванный в Codex скилл применяй после обоих INDEX по полному актуальному SKILL.md запрошенного владельца. Используй прочитанное в сессии, иначе отдельным вызовом прочитай файл или дочитай недостающие фрагменты той же версии.

В Codex требуемую проверку пути к SKILL.md вызови отдельно. Дождись результата. Если допустимость подтверждена, следующим вызовом прочитай только SKILL.md или недостающий фрагмент той же версии. Иначе остановись до чтения.

Загружай только нужные скиллы. Массовое или повторное чтение из-за INDEX — ошибка. Полностью перечитав неизменный скилл, укажи ошибку и путь, запроси решение, жди явного ответа. Изменённую версию прочитай. Соблюдай правила и разрешения.

В списках ссылок ставь START перед INDEX, правила и их каталоги перед скиллами и их каталогами. В каждом стартовом списке AGENTS.md помещай правила между START и INDEX. При изменении генератора проверь создание и восстановление входов в common-only и common+project, включая повторный старт. Сохраняй пользовательские настройки. Переупорядочение защищённых входов проходит через согласованный inbox.
