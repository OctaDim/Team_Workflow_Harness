# Обязательный порядок инструкций harness

После стартовой команды прочитай START common, затем project и указанные ими правила. После полного актуального текста правила сразу отдельным вызовом прочитай скилл по безусловной ссылке, по условной — при наступлении условия. Это действует до перечисления каталога независимо от длины правила. Соблюдай запреты ранней загрузки. Чтение не разрешает действия.

Отдельно перечисли все Markdown-файлы установленной .claude/rules/ рекурсивно, кроме README.human.md. Для чтений через START подтверди установленный путь и содержимое. Остальные правила читай по одному с переходами до следующего правила. Дочитывай фрагменты той же версии. При изменении или неизвестной актуальности прочитай текущую версию. Сверь полное актуальное чтение каждого пути списка.

До добавления безусловной ссылки или снятия условия назови файл и правку, запроси отдельное подтверждение. Дождись явного согласия без записи. Исходное поручение не заменяет ответ. Чтение согласованной ссылки повторного подтверждения не требует.

После сверки прочитай INDEX common, затем project. Явно вызванный в Codex скилл применяй после обоих INDEX. Учитывай полный текст владельца, уже полученный в сессии, включая раннее чтение по ссылке правила. Подтверждённо идентичная установленная копия — та же версия. Используй прочитанное без нового открытия, сравнения или хеширования копий.

Перед чтением SKILL.md в Codex выполни требуемую проверку файла и компонентов пути отдельным вызовом. Дождись результата. При отказе или неопределённости остановись до чтения. При подтверждении следующим отдельным вызовом получи только текст выбранного файла или остаток той же версии. Применяй скилл после получения полного актуального текста.

Загружай только нужные скиллы. Перечитав неизменный скилл целиком, сообщи ошибку и путь, запроси решение и жди ответа. Изменённую версию прочитай. Соблюдай правила и разрешения.

В списках ставь START перед INDEX, правила и их каталоги перед скиллами и их каталогами. В стартовых списках AGENTS.md помещай правила между START и INDEX. При изменении генератора проверь создание и восстановление входов в common-only и common+project, включая повторный старт. Сохраняй пользовательские настройки. Переупорядочение защищённых входов проходит через согласованный inbox.
