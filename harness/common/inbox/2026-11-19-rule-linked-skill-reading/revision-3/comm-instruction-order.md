# Обязательный порядок инструкций harness

После стартовой команды прочитай START common и project. Читай каждое указанное ими правило полностью. Как только получен полный актуальный текст правила, отдельным вызовом прочитай скилл по безусловной ссылке. По условной ссылке читай его при наступлении условия. Это относится и к правилам из START до перечисления каталога. Длина правила значения не имеет. Используй уже полученный полный актуальный текст скилла. Соблюдай прямые запреты ранней загрузки. Чтение само по себе не разрешает описанные действия.

Отдельно получи полный список машинных Markdown в установленной `.claude/rules/` со всеми подпапками, исключая README.human.md. Сверь каждый путь с полным актуальным текстом. Для чтений через START подтверди соответствие пути и содержимого установленному правилу. Остальные правила читай по одному, обрабатывая их ссылки до следующего правила. Дочитывай фрагменты той же версии. При изменении или неизвестной актуальности прочитай текущую версию.

Прежде чем создать безусловную ссылку из правила на скилл или снять условие с существующей ссылки, запроси и получи явное подтверждение пользователя на эту правку. При последующем чтении согласованной ссылки повторное подтверждение не требуется.

Открывай первый INDEX.md только после получения полного списка путей и подтверждения полного актуального чтения каждого правила из него. Читай INDEX common, затем project. Для задачи загрузи только нужные скиллы, затем применяй процедуры в пределах разрешений. Массовое чтение или перечитывание скиллов по одному лишь открытию INDEX — ошибка. Соблюдай правила и при дальнейшей работе.

В списках ссылок ставь START перед INDEX, ссылки на правила и их каталоги — перед ссылками на скиллы и их каталоги. В каждом стартовом списке AGENTS.md помещай правила между START и INDEX. При изменении генератора проверь создание и восстановление входов в common-only и common+project, включая повторный старт. Сохраняй пользовательские настройки. Переупорядочение защищённых входов проходит через согласованный inbox.
