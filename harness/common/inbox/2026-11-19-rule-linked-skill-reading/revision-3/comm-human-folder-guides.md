# Человеческие пояснения

До поиска/чтения/подключения контекста исключи README.human.md на любой глубине:
это человеческие пояснения, не агентские инструкции. Не загружай тела в старт,
индексы, импорты, description, общий cat или сборщики; при поиске используй
-g '!README.human.md'. Для cat передавай явные пути машинных Markdown из ссылок START.md или
из отфильтрованного списка. Глоб *.md не выражает исключение, даже если README сейчас нет.
Личная процедура не отменяет исключение.

Для полного чтения правил сначала отдельным вызовом инструмента получи список:
`rg --files --hidden --no-ignore .claude/rules -g '*.md' -g '!README.human.md'`.
Сверь все пути списка с уже полученными в текущем контексте полными
актуальными текстами. Засчитывай любое число правил через ссылки любого
START.md, включая весь список. Для канонической копии подтверди соответствие
установленного пути и содержимого. Остальные читай по одному отдельными вызовами по явным путям в кавычках. Учитывай вложенные и игнорируемые правила любых имён.
Обрезанный вывод дочитай для той же версии; при изменении или неизвестной
актуальности прочитай текущую версию. Заверши до INDEX. Между правилами соблюдай порядок перехода по ссылкам
из полностью прочитанных правил. Отсутствие списка, свидетельств, пропуск пути и лишнее
полное чтение неизменного правила — ошибки проверки.
При повторном полном чтении покажи пользователю ошибку и точный путь каждого
повторно прочитанного правила в `.claude/rules/`. Спроси, как продолжить,
и остановись до явного решения пользователя.
При создании, изменении и проверке инструкций harness выводи отдельно для
каждого запуска, сценария и режима шесть строк: впервые прочитано через START,
через AGENTS, размер списка, число уникальных прочитанных путей, лишние полные
чтения, результат с фактическими числами и всеми причинами ошибки.

Согласованные категории создавай заранее, даже пустые; каждой новой папке
harness сразу нужен README.human.md с простым пояснением и понятным примером
(в пустой — иллюстративным). Наличие README не доказывает наполненность/проверку.
Программная проверка может читать тела, возвращая только пути/ошибки/результат.

Для оценки инструкций до запуска инструментов открой
`harness/common/skills/comm-validate-harness-instructions/SKILL.md`:
там процедура human-фильтра и отдельных проверок чтения, загрузчиков и поведения.
