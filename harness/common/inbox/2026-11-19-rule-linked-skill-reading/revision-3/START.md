# Обязательные границы

После стартовой проверки прочитай `rules/comm-skill-rule-ownership.md` до выбора
процедуры. AGENTS.md/CLAUDE.md напрямую не редактировать; согласованное создание
и восстановление стартовых ссылок — узкое исключение. Хранение памяти и штатных
материалов Superpowers регулирует `rules/comm-user-owned-entrypoints.md`.

Перед перечислением всех правил прочитай `rules/comm-human-folder-guides.md`:
там способ получить полный список машинных файлов и безопасно прочитать их.

После обоих START читай правила, на которые они указывают. Из полностью
прочитанного правила сразу переходи отдельным вызовом к скиллу по безусловной
ссылке, по условной — при наступлении условия. Это допустимо и до перечисления
каталога. Соблюдай запреты ранней загрузки и используй уже прочитанный
актуальный текст. Отдельно перечисли все правила и сверь по путям, какие
полностью прочитаны в текущей версии. Остальные читай по одному с теми же
переходами. Только после полного покрытия списка открывай INDEX common, затем
project. Чтение скилла не даёт разрешения выполнять его действия.
