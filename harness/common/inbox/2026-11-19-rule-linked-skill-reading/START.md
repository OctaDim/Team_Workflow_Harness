# Обязательные границы

После стартовой проверки прочитай `rules/comm-skill-rule-ownership.md` до выбора
процедуры. AGENTS.md/CLAUDE.md напрямую не редактировать; согласованное создание
и восстановление стартовых ссылок — узкое исключение. Хранение памяти и штатных
материалов Superpowers регулирует `rules/comm-user-owned-entrypoints.md`.

Перед перечислением всех правил прочитай `rules/comm-human-folder-guides.md`:
там способ получить полный список машинных файлов и безопасно прочитать их.

После обоих START перечисли правила отдельным вызовом. Учти полные актуальные
чтения через START. Сразу обработай применимые ссылки из уже зачтённых
правил, прежде чем читать первое оставшееся правило. Остальные читай по одному.
Перед следующим правилом отдельным вызовом прочитай скилл, если полученное
правило уже требует этого для текущей задачи. Соблюдай запреты ранней загрузки.
Затем прочитай INDEX common и project. Используй уже прочитанный актуальный
текст. Открытие скилла не даёт разрешения выполнять его действия.
