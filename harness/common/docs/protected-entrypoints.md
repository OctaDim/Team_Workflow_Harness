# Проверка входов без индивидуальной настройки

Уточнение пользователя 2026-10-05 отменяет Git hook, блокирующие проверки и обязательную регистрацию версии входов. Прямое редактирование AGENTS.md и CLAUDE.md запрещено договорённостью harness, но технически не заблокировано. Предложения изменения — через согласованную отдельную обработку inbox. Наличие заявки само по себе не разрешает правку.

## Запуск

Нужен Python 3.9+. Из корня проекта:

```sh
python3 -B harness/common/checks/ensure_entrypoint_links.py
```

Не требуются Git, hooks, hooksPath, изменения конфигурации машины или предварительная регистрация входов. Скрипт не запускается сам: его запускает агент по стартовой инструкции. Он не изменяет Git-настройки и не блокирует запись или коммит.

## Что проверяется

- Наличие INDEX.md/START.md установленных пакетов и обычные безопасные входные файлы.
- Стартовые Markdown-ссылки в AGENTS.md и относительный импорт в CLAUDE.md. Перед восстановлением выводится сообщение о повреждении и предстоящей записи. Другие настройки не переписываются.
- CLAUDE.md должен содержать только @AGENTS.md и необязательный конечный перевод строки. Лишний или отличающийся текст сохраняется; проверка предупреждает и направляет исправление в inbox.
- Если Git уже доступен и содержит версии входов в HEAD, дополнительно сравнивается рабочий текст с историей. Для AGENTS.md стандартные строки стартовых ссылок не считаются изменением настроек. Обнаруженная правка вызывает предупреждение, а не блокировку.

При отсутствии Git или версии HEAD сравнение произвольных настроек AGENTS.md с прошлым не проверено: без предыдущего текста нельзя доказать их неизменность. Структура и импорт проверяются независимо. Текущее содержимое не сохраняется автоматически как новое основание сравнения.

Сообщение проверки:

> Прямое редактирование AGENTS.md и CLAUDE.md запрещено договорённостью harness, но технически не заблокировано. Изменения предлагайте через заявку в harness/<пакет>/inbox/.

Предупреждения об изменённом тексте не меняют код успешного завершения и не блокируют задачу. Повреждение ресурсов, небезопасные пути и ошибки чтения/записи могут завершить проверку ошибкой: это невозможность безопасно выполнить её, а не технический запрет редактирования.

## Проверки

```sh
python3 -B harness/common/checks/test_ensure_entrypoint_links.py
python3 -B harness/common/checks/test_entrypoint_notifications.py
```

Проверяются работа без Git, сохранение прямых правок и лишнего текста, предупреждение до записи восстановленных ссылок, отсутствие ложного сообщения о повреждении, отсутствие установленных hooks/новых настроек и возможность обычного коммита после предупреждения.

В целевом проекте удалён только hook, установленный в этой задаче; чужие hooks не трогались. Старое описание блокировки и старые тесты блокирующей политики сохраняются в истории Git; они не являются действующим контрактом.

## Незавершённое

Project-only пока не содержит собственного скрипта, а шаблон требует common. Нужен отдельный выбор способа независимости, без отмены запрета дублирования знаний. Трёхрежимная переносимость и фактическая нативная загрузка Codex/Claude Code ещё не приняты.
