# Обязательный порядок инструкций harness

После стартовой команды прочитай START common и project, затем полностью указанные ими правила. Получив полный актуальный текст правила, отдельным вызовом прочитай скилл по безусловной ссылке, по условной — при наступлении условия. Это действует и до перечисления каталога независимо от длины правила. Между правилом и INDEX используй уже прочитанный скилл. Дочитывай фрагменты той же версии. Если повторно прочитал неизменный скилл полностью, сообщи ошибку и путь, запроси решение пользователя и остановись до явного ответа. После изменения читай новую версию. Соблюдай прямые запреты ранней загрузки. Чтение не разрешает действия.

Отдельно перечисли все машинные Markdown установленной `.claude/rules/` рекурсивно, кроме README.human.md. Сверь каждый путь с полным актуальным текстом. Для чтений через START подтверди установленный путь и содержимое. Остальные правила читай по одному, обрабатывая их ссылки до следующего правила. Дочитывай фрагменты той же версии. При изменении или неизвестной актуальности прочитай текущую версию.

До добавления безусловной ссылки или снятия условия проверь диалог: задал ли агент вопрос о конкретной правке и получил ли затем явное согласие? Исходное поручение не заменяет этот ответ. Если согласия после вопроса ещё нет, назови файл и правку, запроси подтверждение и остановись без записи. При последующем чтении согласованной ссылки подтверждение не требуется.

Открывай INDEX common, затем project только после полного списка путей и подтверждения полного актуального чтения каждого правила. Для задачи загрузи только нужные скиллы, затем применяй процедуры в пределах разрешений. Массовое чтение или перечитывание скиллов по одному лишь открытию INDEX — ошибка. Соблюдай правила и при дальнейшей работе.

В списках ссылок ставь START перед INDEX, ссылки на правила и их каталоги — перед ссылками на скиллы и их каталоги. В каждом стартовом списке AGENTS.md помещай правила между START и INDEX. При изменении генератора проверь создание и восстановление входов в common-only и common+project, включая повторный старт. Сохраняй пользовательские настройки. Переупорядочение защищённых входов проходит через согласованный inbox.
