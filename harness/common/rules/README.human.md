# Rules — пояснение для человека

Здесь хранятся короткие действующие инструкции агентам: условие применения, обязательный порядок или ограничение, признак нарушения. Длинные объяснения решений хранятся в соответствующей категории, когда она появится.

Пример: package-independence.md требует отдельного переноса common без project. Совместный успешный запуск не заменяет эту проверку: нужный файл может случайно оказаться у соседа.

Эти пояснения предназначены для человека; рабочие инструкции находятся в отдельных файлах правил.
