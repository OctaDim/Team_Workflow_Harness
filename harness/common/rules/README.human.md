# Короткие обязательные правила

Эта папка хранит ограничения, которые агент должен учитывать до опасного действия или выбора процедуры. Здесь нет подробных разборов инцидентов: они хранятся в lessons/, а решения — в decisions/.

Пример: comm-skill-rule-ownership.md запрещает индивидуальному скиллу отменять требование общего скилла. Даже если личная процедура предлагает пропустить проверку ради скорости, агент должен выполнить применимое каноническое требование.

Префикс comm- обозначает общий канонический материал. Индивидуальные правила и установочные копии размещаются в нативных каталогах по отдельному контракту; они не заменяют оригиналы этой папки.

Это пояснение предназначено только человеку. AI-агент не должен читать его тело или включать его в контекст.
