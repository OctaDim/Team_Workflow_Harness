# rules/ — пояснение для человека

Короткие действующие инструкции агентам. Условие применения, порядок или ограничение и признак нарушения.

Универсальные материалы, применимые в разных проектах.

Пример: Правило независимости пакетов: проверять перенос каждой папки отдельно.

Такой короткий контракт помогает заметить ошибку до повторного переноса.

Здесь уже есть три начальных правила: package-independence.md, human-folder-guides.md и user-owned-entrypoints.md. Их наличие не означает, что весь harness наполнен и подключён к агентам.
