# Локальный коммит при завершении работы

Перед итоговым ответом по завершённой задаче с изменениями в репозитории
или переходом к следующей заявке INBOX найди установленный скилл по
точному имени `comm-commit-task-stages`, прочитай и примени его. Если
он недоступен или неоднозначен, сообщи причину и останови коммит.

Если результат проверен и разрешений достаточно, сделай локальный коммит
по этому скиллу без отдельной команды пользователя. В простом маршруте
применяй требуемый им `ce-commit` для этой операции.

Сообщи хеш и точный заголовок каждого созданного коммита, причину пропуска
или конкретную блокировку.
