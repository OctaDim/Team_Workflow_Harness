# Явный вызов скилла и выбор маршрута

20 ноября 2026 года. Кандидат v2 к базе `2667190`. Проверялось решение до начала предметной работы. Для одной операции Codex применяет названный скилл или плагин. При выборе полного процесса он приступает к его первому этапу. При открытом выборе маршрута показывает меню и ждёт ответа. Отдельные разрешения проверяются перед соответствующим действием.

Постоянное правило определяет, когда можно загрузить процедуру и когда нужно дождаться выбора. Существующий скилл владеет порядком выбора и шаблоном меню. Только скилл не устраняет конфликт до его загрузки. Перенос меню и деталей в одно правило увеличил бы постоянный контекст.

## Нативная проверка

Codex CLI 0.166.0, обычный профиль, отдельный диалог `codex -a never exec --ephemeral -c features.multi_agent=false --sandbox read-only` на сценарий. В common-only стартовая проверка создала нейтральный project. В common+project использовалась копия существующего project. В каждом режиме в каталоге найдена ровно одна активная запись процедуры выбора. Перед прогонами сверены канонические и нативные копии кандидата. Реальные скиллы использовались в учебных рабочих каталогах.

На исходной версии все три формы явного запроса привели к диагностике без показа меню. При формах с `$` и `/` Codex при этом прочитал ресурс меню. Эпизод ожидания выбора из исходной заявки в этих контрольных прогонах не воспроизвёлся.

На первой версии явный вызов, выбор полного процесса и вопросы при открытом выборе отработали по назначению. В ответах с меню Codex называл Superpowers недоступным, хотя в тех же установках нашёл и применил его. Для второй версии уточнён вывод о пропущенном в каталоге имени. Завершённые прогоны подтверждали поведение по ответу и событиям чтения. Для диагностики искали запрос лога упавшего шага, для плагина редактуры — исправленную фразу, для полного процесса — переход к обсуждению требований, для меню — варианты, ожидание выбора и обращения к ресурсам. Учебный случай с отклонённой отправкой журнала проверял запрос разрешения на конкретное дальнейшее действие.

Первые прогоны v2 дали 5 завершённых ответов из 22. В 11 трассах CLI сообщил `workspace routing discovery failed`, в 6 истёк таймаут наблюдения. Для прерванных случаев повторяли тот же запрос в том же каталоге. Все попытки сохранены раздельно. Фактические результаты финальной версии — 11/11 и 11/11.
