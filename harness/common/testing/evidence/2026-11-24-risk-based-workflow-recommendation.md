Первый сбой стартового порядка остаётся результатом проверки.

Порядок записи подтверждён по завершённой команде записи с кодом 0 до первого сообщения с вопросом. Коды выхода CLI для сценариев — 0; оценки поведения выше основаны на журнале команд, содержимом записей и ответах.
