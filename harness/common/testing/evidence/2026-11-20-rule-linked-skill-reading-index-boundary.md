# Граница первого чтения INDEX

20 ноября 2026 года. Это проверка предложенного порядка заявки № 5. Установленные правила относятся к коммиту `823637b`. Для проверки использованы [уточнённое правило](../../inbox/2026-11-19-rule-linked-skill-reading/revision-3/comm-instruction-order-v4.md), [START](../../inbox/2026-11-19-rule-linked-skill-reading/revision-3/START.md) и [аудитор](../../inbox/2026-11-19-rule-linked-skill-reading/revision-3/check_human_guide_search.py). [Предыдущая редакция и методика](2026-11-20-rule-linked-skill-reading.md)

У проверки два независимых условия. Для скилла требуется полный актуальный текст правила и действующая сейчас ссылка. Это допускает переход по правилу из START ещё до перечисления каталога. Для первого INDEX требуется завершившийся отдельный вызов перечисления и подтверждение полного актуального текста каждого указанного пути. Просмотр имён, неполный текст и последующее исправление порядка не удовлетворяют этому условию.

Регрессия с 12 заранее прочитанными правилами вставляет чтение INDEX непосредственно перед получением списка. В common-only и common+project аудитор сообщает «INDEX открыт до получения полного списка правил». Добавление списка позднее сохраняет ошибку первого открытия. Контроль с открытием INDEX после списка и всех полных текстов проходит. Отдельно проверены допустимые ранние переходы по ссылке, условие, наступившее позднее, запрет чтения по неполному правилу и просмотр метаданных INDEX без открытия его тела. Прогоны с 1 и 1200 строками дополнительного текста дали одинаковые результаты.

В третьей редакции единичная проверка добавления безусловной ссылки зафиксировала запись в учебный файл до согласия. В четвёртой редакции явно разделены первоначальное поручение и ответ на вопрос о конкретной правке. Остальные файлы кандидата лежат рядом с правилом. Для проверки кандидат устанавливался в тестовую копию под штатными именами. Команды pytest и нативных прогонов приведены в предыдущем отчёте. Шестистрочные отчёты, исходные и пересчитанные результаты, хеши файлов и параметры запусков приведены в [данных проверки](2026-11-20-rule-linked-skill-reading-index-boundary.json).
