## Требования и выбор формы

| Исходный контракт | Владелец при lazy-only | Проверка |
| --- | --- | --- |
| Открыть до первого действия workflow, требующего коммита | metadata/самостоятельный выбор скилла | не проверено; главный предмет опыта |
| Common-политика выше частых коммитов внешнего workflow | действующая общая приоритетность + comm-commit-task-stages | не проверено; сценарий внешнего workflow |
| Вопрос, ответ, сохранение или мелкая правка не граница | текущий SKILL.md | текст сохранён; поведение не проверено |
| Завершённый полезный результат и исключения | текущий SKILL.md | текст сохранён; поведение не проверено |
| Проверки, согласования, изоляция и восстановление | текущий SKILL.md и действующие common-границы | текст сохранён; поведение не проверено |
| Только свои пути, exclude и сохранность чужого staged | текущий SKILL.md | наблюдение реального Git подготовлено, не выполнено |
| ce-commit, пропавший инструмент/ошибка, без расширения на push/PR/merge | текущий SKILL.md | текст сохранён; поведение не проверено |

Rule-only не даёт самостоятельного алгоритма и оставляет указатель на скилл;
в этой форме не подготовлен кандидат с достаточным контрактом.
Lazy-only — остающаяся гипотеза; структурная переносимость подтверждена,
discovery/behavior без правила ещё нет. Rule+skill сохраняется действующим;
необходимость ранней границы metadata пока не опровергнута и не доказана опытом.
Новый текст скилла не сочинялся до получения baseline-наблюдений.

## Контекст и компактность

Во всех временных установках сумма размеров машинных файлов правил:
43624 bytes для пары и 42690 bytes для lazy-only; разница 934 UTF-8 bytes.
Метаданные всех доступных native-скиллов одинаковы: 3501 UTF-8 bytes.
Это частичные статические компоненты старта, без START/INDEX/прочих guards,
а не полный стартовый бюджет. Тело целевого скилла неизменно: 1581 bytes.

Analyzer для скилла: trigger 44 / invoke 396 / deferred 0 estimated tokens.
Фактические thresholds/bands сохранены в JSON; пороги не изменялись.
Generic analyzer оценивает текст правила в 137 статических токенов как deferred;
это категория analyzer для directory, а не фактическая lazy-семантика правила.
Сокращение постоянного контекста не доказано как расход сессии или денежная экономия.
Actual task reads со всеми зависимостями и usage успешного поведения недоступны,
это неизвестные данные, не нулевые значения. Full available resources других
владельцев отдельно не переоценивались; полное контекстное сравнение не завершено.
