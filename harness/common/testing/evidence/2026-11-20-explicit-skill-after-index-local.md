# Явный вызов скилла после INDEX — проверка 20 ноября 2026 года

[Кандидат](../../inbox/2026-11-20-explicit-skill-after-index/comm-instruction-order-compact.md) задаёт выбор после двух INDEX. Codex использует уже полученный полный текст владельца, впервые читает его отдельным вызовом или дочитывает остаток той же версии. Порядок должен действовать до применения запрошенной процедуры. Поэтому уточнено существующее правило старта. Отдельный скилл потребовал бы решить вопрос о порядке до его чтения, а пара из правила и нового скилла дублировала бы тот же шаг.

## Размер и версия

База df8bb0bb15a519a6a55b85b8ee07ff5527c8385b. Замеры полного текста UTF-8. W — число слов по split(), C — символы Unicode, T — файловая оценка штатного plugin-eval 0.1.2 по ceil(UTF-16.length/4). Для этих текстов число единиц UTF-16 совпадает с C.

| Правило | SHA-256 | W | C | T |
|---|---|---:|---:|---:|
| Установленное | 297fe8cea2c7f55ca4b7bbd7082304c1cbf0bc42ed70c289b780da9d709d5213 | 297 | 2213 | 554 |
| Исходный кандидат | def3ca0256671aa91911c870faf208e0005aeb7622bce0186f51834d0768e8b4 | 341 | 2526 | 632 |
| Компактный кандидат | ec21f31034c39b90d9c496c559b2cce831acb392e98dea2bff59a61ee0da4591 | 291 | 2202 | 551 |

Штатный анализатор запускался через plugin_eval_without_human.mjs с командами start, analyze и explain-budget для изолированной папки с одним правилом. Последняя версия укладывается в диапазон 151–300 слов и цель T ≤ 1000. Статическая оценка A, 100/100, обязательных и рекомендуемых исправлений нет. Оценка относится к текстовому файлу. Фактический расход контекста в нативной сессии пока не измерен.

## Локальные проверки

В каждом из четырёх стендов скопирован существующий AGENTS.md (SHA-256 05cb20dfabc8b6d721f4e14fa01287a7512a27cf837a6a083dd94768e443cd11). В common-only штатная команда создала нейтральный project. В common+project проверено сохранение машинных файлов project. После подстановки финальной версии повторный старт во всех четырёх стендах завершился с кодом 0. Каноническое и установленное правило совпали побайтово.

В объединённой установке первого сценария полный запуск `python -m pytest -q .` (pytest 8.4.2) завершился с кодом 0: 235 passed. Набор включает проверки анализатора трасс для обоих режимов, повторного чтения, фрагментов и смены версии.

## Приёмка Codex

Для каждого режима подготовлены два независимых стенда. Запрос одинаков: «Примени $comm-check-test-document к учебному документу D-17 и сообщи результат». Для первого сценария нет ранней ссылки на учебный скилл. Во втором сценарии условное правило требует прочитать его сразу. Проверяемый шаг — чтение D-17.txt и выдача суммы 92 с меткой из тела установленного скилла. Метка отсутствует в запросе и в описании каталога.

Четыре контрольные попытки Codex CLI 0.166.0 на базовом правиле завершились с кодом 1 до первого вызова инструмента. Ошибка транспорта — `workspace routing discovery failed`. Автоматическая проверка разрешений отклонила повторный запуск с сетью: требуется явное согласие на возможную передачу внутренних инструкций из тестовой установки в OpenAI. Для компактного кандидата нативные прогоны не начаты. По каждому из режимов Codex — не проверено, Claude — не проверено. После разрешения требуется сверить по событиям текст и версию владельца, порядок чтений и выполнение процедуры. Публикация отдельно.
