# Учёт правил, прочитанных через START

19 ноября 2026 года. Codex CLI 0.166.0 прошёл проверку чтения и поиска в common-only и common+project. Claude — непроверенный. Итоговый статус — непроверенный. Кандидат правила имеет SHA-256 `62d1c55590f75cf70c6681f2ddbaede8c0f001708f75bfe02151a6a1a9e14de1`. [Заявка и три файла кандидата](../../inbox/2026-11-19-reuse-complete-rule-reads/request.md) · [Шестистрочные отчёты по сценариям, пути, версии и хеши](2026-11-19-reuse-complete-rule-reads.json)

## Результат

Полный актуальный текст можно получить через любой START. Количество ссылок, имя правила и глубина вложенности не ограничены. Аудитор сопоставляет установленный путь с текстом, проверяет байты канонической копии, учитывает дочитанные строки и отделяет уникальные пути от лишних полных чтений. Неполный список, отсутствие подтверждения или преждевременный INDEX дают ошибку. Контроль применяется до выбора скилла, поэтому уточнено существующее правило. Отдельный скилл загрузился бы после контролируемого действия. Пара из нового правила и скилла дублировала бы существующих владельцев.

## Проверки кандидата

| Проверка | common-only | common+project |
|---|---|---|
| Два запуска штатной команды в чистой установке | Создан и сохранён нейтральный project | Сохранены байты существующего project |
| Контролируемое чтение действительных файлов через все ссылки START, затем каталог | 3 + 9, 12 уникальных, 0 повторов | 3 + 9, 12 уникальных, 0 повторов |
| Codex, чтение всех правил и открытие скилла | 4 + 0, 4 уникальных, 0 повторов | 4 + 0, 4 уникальных, 0 повторов |
| Codex, рекурсивный поиск с исключением человеческих пояснений | 1 + 0, один поиск, ожидаемые совпадения | 1 + 0, один поиск, ожидаемые совпадения |

Локальные регрессии используют 0, 1, 2, 5 и 12 правил через START. Для комбинаций из заявки подтверждены успех 12/12 без повторов и три отказа — 10/12, 12/12 с тремя повторами, 11/12 с одним повтором. Есть проверки дочитывания, устаревшей версии, одинаковых имён в разных каталогах, пропущенного списка, совмещённых и пересекающихся вызовов. В JSON у каждого обращения к аудитору сохранён свой отчёт. Ошибка в отрицательном сценарии является ожидаемым результатом теста.

RED на исходном аудиторе дал 17 упавших и один прошедший тест. После исправлений прошли все 23 целевых теста. Полный запуск `python -m pytest . -q --tb=short` в отдельной копии коммита `24800d9` с кандидатом на штатных путях дал 217 прошедших, код выхода 0. Использованы Python 3.12 и pytest 8.4.2 из проектного lock-файла. Для воспроизведения подставить три файла заявки в `harness/common/rules/`, `harness/common/checks/`, `harness/common/testing/tests/` соответственно и ту же копию правила в `.claude/rules/` изолированной установки.

Нативные сценарии запускали `check_human_guide_search.py` с `--task read` и `--task search`, каждый с `--mode common` и `--mode both`. Codex выполнил все четыре задания в изоляции. Контрольный маркер человеческого текста отсутствует в событиях. В промежуточных версиях аудитор пропускал полный вывод из цикла с явными путями и терял подтверждение при последующем сравнении копий. Окончательная проверка чтения сопоставляет явные пути и содержимое вывода. Каталог нативной фикстуры смонтирован только для чтения. Для обычных изменяемых трасс сохраняется требование заново получить текст при неизвестной актуальности. Уточнение проверки обратного порядка совмещённого вызова проверено повторным анализом четырёх сохранённых трасс той же версии правила. Хеш аудитора нативного запуска и хеш окончательного анализатора указаны раздельно.

Статический plugin-eval 0.1.0 дал A и не предложил обязательных или рекомендуемых исправлений. Его информационные замечания относятся к анализу обычного каталога и отсутствию переданного отчёта покрытия. Оценка исходного правила — 183 слова, 1526 символов, 382 статических токена. У кандидата 263 слова, 2109 символов, 528 статических токенов. Обе оценки по словам в диапазоне 151–300, целевой предел оценки токенов 1000. Прирост 146 статических токенов относится к учёту версий, повторов и отчёту. Новых зависимостей, ресурсов и метаданных скилла нет. Фактические объёмы вывода команд и данные использования CLI приведены по каждому финальному сценарию отдельно.

## Повторная оценка исторических трасс

Хеши всех четырёх исходных трасс сверены с [опубликованным протоколом прежней проверки](2026-11-19-codex-startup-publication-check.md). Для согласованной версии common+project последовательность «2 + 10» прошла. В common-only две копии повторно прочитаны после списка, результат 14 чтений для 12 путей. В уточнённой версии common-only тот же повтор, а в common+project INDEX открыт до полного списка. Исходные отчёты сохранены. Эти выводы касаются только критерия чтения.

В старте рабочего чата первый объединённый вывод правил был обрезан, а INDEX был открыт до отдельного сверенного списка. Более позднее полное чтение не восстанавливает свидетельство на момент первого INDEX. Для этого старта результат — ошибка проверки, точные счётчики на момент границы не подтверждены.

```text
Правила `.claude/rules/` через ссылки в START.md: нет данных
Правила `.claude/rules/` через ссылку на `.claude/rules/` в AGENTS.md: нет данных
Всего правил в `.claude/rules/`: нет данных на момент первого INDEX
Всего правил прочитано: нет данных
Повторно прочитанных правил: нет данных
Результат: Ошибка - до первого INDEX нет отдельного полного списка и подтверждения прочитанных путей
```
