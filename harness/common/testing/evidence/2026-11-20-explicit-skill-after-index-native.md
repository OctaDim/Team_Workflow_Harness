# Нативная приёмка явного вызова скилла после INDEX

20 ноября 2026 года. [Кандидат](../../inbox/2026-11-20-explicit-skill-after-index/comm-instruction-order-compact.md) с SHA-256 `ec21f31034c39b90d9c496c559b2cce831acb392e98dea2bff59a61ee0da4591` прошёл все четыре сценария Codex CLI 0.166.0 (gpt-6.2-sol, medium). Для Claude в обоих режимах статус «непроверенный». Итоговый статус версии — «непроверенный». [Локальные проверки и размеры правила](2026-11-20-explicit-skill-after-index-local.md).

В каждой сессии использованы независимый профиль, учебный скилл с собственной контрольной меткой и доступная только для чтения установка. Во всех стендах копия действующего AGENTS.md имеет SHA-256 `05cb20dfabc8b6d721f4e14fa01287a7512a27cf837a6a083dd94768e443cd11`. Оба режима получили один запрос без подсказок о порядке чтения. Для сценария повторного использования отдельное учебное правило требует раннего чтения того же владельца. Файл D-17.txt содержит 58 и 34. Правильный ответ должен включать сумму 92 и метку из SKILL.md.

## События и результаты

## Воспроизводимость

В [архиве](2026-11-20-explicit-skill-after-index-native.zip) сохранены восемь исходных журналов, протокол сопоставления с SHA-256, учебные файлы каждого стенда и сценарии подготовки, запуска и анализа. Стенд воспроизводится из базового коммита df8bb0bb15a519a6a55b85b8ee07ff5527c8385b и компактного кандидата. При повторном создании учебный скилл получает случайную метку; архив содержит точные версии из измерения. Явный запуск выполнялся с параметрами `--ignore-user-config --skip-git-repo-check -s read-only -m gpt-6.2-sol` и выводом JSON. Отдельная проверка DNS понадобилась, поскольку /etc/resolv.conf ссылается на файл под /mnt/wsl. Ранние сетевые попытки без этого файла не являются поведенческими испытаниями.
