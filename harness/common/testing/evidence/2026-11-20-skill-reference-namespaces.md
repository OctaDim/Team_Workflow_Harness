# Заявка № 6. Разрешение имён до замены ссылок

20 ноября 2026 года, база `5977ea3`. В действующих правилах, скиллах и рабочих ресурсах common и project сверены 91 машинный файл и 170 установленных копий. Все пары совпали побайтово. Найдено 75 употреблений имён в 22 файлах, соответствующих 33 целевым скиллам. Реестр содержит путь, строку, колонку, исходную формулировку, целевой идентификатор и результаты по режимам. К ссылкам по имени отнесены также условные маршруты, указания пропустить вызов и обработка отсутствующей обязательной зависимости. Прямые пути, упоминания утилит и описательные совпадения учитывались отдельно. [Реестр и состав сверенных файлов](2026-11-20-skill-reference-namespaces-inventory.json)

Штатный `skills/list` Codex CLI 0.166.0 в двух отдельных тестовых каталогах вернул по 173 записи в исходном снимке. Из 33 нужных имён по 20 имели ровно одно включённое совпадение в каждом режиме. Локальным и системным скиллам каталог даёт короткое имя, например `comm-commit-task-stages` и `skill-creator`. Для Compound Engineering он даёт форму `compound-engineering:ce-commit`. Для 13 имён Superpowers, Plugin-eval и Plugin-management в этом профиле CLI совпадений нет. Эти имена присутствуют в каталоге текущей сессии Desktop. Из наличия в Desktop или на диске нельзя вывести факт их вызова в CLI. Для Claude Code результаты нативного вызова остаются непроверенными.

На этапе проверки коллизии кэш Compound Engineering обновился с 3.38.0 до 3.38.2. В common-only первая попытка прочитать старый путь вернула ошибку. Успешное чтение актуальной версии подтверждено отдельно. У обоих владельцев совпадает часть имени после двоеточия. В каталоге контрольных установок зарегистрированы две разные записи — `ce-commit` и `compound-engineering:ce-commit`. Ни один ответ не использовал результат локального контрольного скилла. [Условия, события чтения и ответы шести диалогов](2026-11-20-skill-reference-namespaces-probes.json)

Для продолжения замены нужно согласовать представление локальных и системных имён. Рабочая форма для зависимости восстановления уже подтверждена по короткому зарегистрированному имени. Применение всех 33 зависимостей и четыре сценария авторства ещё не подтверждены. Кандидат контракта авторства остаётся в Inbox.
