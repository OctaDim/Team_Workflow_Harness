# Common — пояснение для человека

Здесь хранятся универсальные знания, применимые в разных проектах. Категории разделяют исходные ограничения, решения, уроки, тестирование, правила, навыки, проверки, очередь, документацию и передачу задач.

Пример: проверка ссылки после отдельного копирования пакета полезна независимо от языка приложения. Для конкретной команды запуска используется конфигурация принимающего проекта.

Структура создана заранее; сейчас имеются три начальных правила. Полная работоспособность пакета ещё не подтверждена.
