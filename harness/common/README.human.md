# Common — пояснение для человека

Эта папка предназначена для знаний, применимых в разных проектах: правил работы агентов, процедур, навыков и проверок. Детали отдельного приложения сюда не переносятся автоматически.

Пример: правило независимости требует проверять пакет отдельно от соседнего. Благодаря этому при переносе common в другой проект не теряются нужные ресурсы. Само наличие правила ещё не подтверждает независимость всего пакета.

Сейчас здесь начальные правила и индекс; полный набор категорий ещё согласуется.
