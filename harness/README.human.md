# Harness — пояснение для человека

Здесь находятся два переносимых пакета с одинаковыми категориями: common для универсальных знаний, project для материалов исходного проекта EPL. Каждый имеет собственный индекс.

Пример: процедура проверки переносимого пакета относится к common, решение о модели путевого листа — к project. Так опыт переносится без навязывания другой предметной области.

Созданы категории обеих папок, включая handoff. Это каркас; наполнение, подключение агентов и полная приёмка ещё впереди.
