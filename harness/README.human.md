# Harness — пояснение для человека

Здесь располагаются переносимые пакеты знаний: common для универсального опыта, project для знаний исходного проекта. У каждого пакета свой индекс и свои ресурсы.

Пример: общая процедура проверки битых ссылок относится к common, контракт XML путевого листа — к project. Первый применим в разных проектах; второй привязан к предметной области.

Пока создан только начальный common; project ещё не собран. Пример показывает назначение будущих пакетов, а не подтверждает их готовность.
