# Два пакета harness

Здесь находятся common/ с общими переносимыми знаниями и project/ с материалами исходного проекта EPL. В обоих пакетах одинаковые десять категорий, собственные INDEX.md и START.md.

Пример: общая проверка входных ссылок находится в common/checks/, а первичный анализ EPL — в project/docs/epl-harness-audit.md.

Первый материал описывает механизм harness, второй — наблюдения о конкретном исходном проекте. Их разделение позволяет переносить общий опыт отдельно от предметных знаний.

Категории созданы заранее. В common уже есть правила, скилл, решения, уроки и проверки; в project — первичный отчёт и автономная копия проверки входа. Полная приёмка обоих пакетов ещё не завершена. Заявки inbox временные; необходимые результаты хранятся в постоянных категориях.

Это пояснение для человека. При обычной работе агента его тело не входит в инструкции, поиск знаний или оценку скилла.
