# checks/ — пояснение для человека

Механические проверки и их тесты. Скрипты проверки harness и проверяемые примеры нарушений.

Материалы исходного проекта EPL; правила других проектов сюда не подставляются.

Пример: Проверка связи правила EPL с защищаемым регрессионным тестом.

Она проверяет конкретный контракт приложения; пустая папка ещё не обеспечивает защиту.

Пример иллюстративный. Структура создана заранее; рабочие материалы категории ещё предстоит собрать и проверить.
