# Project — пояснение для человека

Здесь хранятся знания исходного проекта EPL. Названия категорий совпадают с common, но предметные факты, ресурсы и проверки принадлежат этому пакету.

Пример: контракт XML путевого листа нужен при работе с EPL. При использовании общего harness в другом приложении такой контракт не должен становиться его правилом.

Пример иллюстративный. Пока создан каркас и собственный индекс; знания EPL ещё не извлечены.
