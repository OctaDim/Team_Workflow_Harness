# inbox/ — пояснение для человека

Подтверждённые материалы для обработки. Предложения, контекст и требуемый результат, сохранённые после подтверждения пользователя.

Материалы исходного проекта EPL; правила других проектов сюда не подставляются.

Пример: Подтверждённый материал о решении ошибки обработки путевого листа.

Он сохраняет контекст для последующей обработки и ещё не является действующим правилом.

Пример иллюстративный. Структура создана заранее; рабочие материалы категории ещё предстоит собрать и проверить.
