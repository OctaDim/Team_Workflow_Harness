# Старт пакета EPL

Если подключён только этот пакет, его собственная команда из корня проекта:

```sh
python3 -B harness/project/checks/ensure_entrypoint_links.py
```

Согласованный новый статичный вход уже указывает её; второй запуск не нужен.
В совместном режиме используется команда статичного входа. Затем ищи материалы
EPL по категориям INDEX.md; подробности открывай по задаче.
