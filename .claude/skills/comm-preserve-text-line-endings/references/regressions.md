# Регрессии исходных байтов

Временные файлы с LF, CRLF, смешанными окончаниями и отсутствующей последней новой строкой подтверждают, что разрешённый участок изменён точно, а остальное сохранилось побайтно. Проверить повтор, ошибку UTF-8, режим и доступные метаданные, конкурентное изменение, ошибку записи/замены и очистку временного файла.

Защищённые AGENTS.md и CLAUDE.md сравнивать с точным каноническим образцом. Для отсутствующего входа подтвердить побайтное создание, для существующего расхождения — отказ до записи. Повторить в изолированных common-only и common+project без Git и с доступным Git. Для подготовки окружения прочитай файл `harness/common/skills/comm-install-harness/references/testing.md`. Фактические проверки и ограничения переносимости зафиксировать отдельно.
