# Проверка статичного входа

До задачи запусти из корня проекта:

```sh
python3 -B harness/common/checks/ensure_entrypoint_links.py
```

Перед записью восстановленных ссылок показать: «Стартовые ссылки повреждены и будут
автоматически восстановлены.» При целых ссылках сообщение не выводить.
[Прямые правки запрещены договорённостью](comm-user-owned-entrypoints.md), но технически
не заблокированы. Проверка выводит предупреждение и направляет изменения в inbox;
она не блокирует редактирование или коммит и не устанавливает hooks.

Нужен только Python 3.9+, индивидуальные настройки не нужны.
[Что проверяется](../docs/protected-entrypoints.md) читай при диагностике.
Текущая команда требует common: project-only ещё не исправлен и не принят.
