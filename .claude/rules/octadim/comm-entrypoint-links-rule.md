# Проверка защищённого входа

До задачи запусти из корня проекта:

```sh
python3 -B harness/common/checks/ensure_entrypoint_links.py
```

Перед записью восстановленных ссылок показать: «Стартовые ссылки повреждены и будут
автоматически восстановлены.» При целых ссылках сообщение не выводить.
Действует [запрет прямых правок](comm-user-owned-entrypoints.md); при нарушении —
предупреждение, остановка зависимой задачи и заявка в inbox.

Нужны Python 3.9+ и Git. [Подключение и границы защиты](../docs/protected-entrypoints.md)
читай при установке или диагностике. Защита коммита требует согласованной версии HEAD
и установленного hook; инструкция не является автоматически запускающимся hook.
Текущая команда требует common: project-only ещё не исправлен и не принят.
