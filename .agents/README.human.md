# Нативные материалы Codex

Проектный каталог нативных материалов Codex. В skills/ находятся установленные общие скиллы и, при явно выбранном личном режиме, индивидуальные скиллы разработчика.

Пример: skills/comm-create-lazy-claude-codex-skills/ содержит полную установленную копию общего скилла.

Для общего скилла источником служит harness, для личного — его папка в .agents/skills/. Эти режимы имеют разные требования к Git; общий источник и копии не скрываются.

Это пояснение для человека. При обычной работе агента его тело не входит в инструкции, поиск знаний или оценку скилла.
