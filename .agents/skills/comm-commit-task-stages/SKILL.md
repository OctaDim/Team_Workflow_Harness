# Commit completed results

Use compound-engineering:ce-commit for every local commit.

Commit completed tasks or substantive independently useful, verified substages.
Labels, task entry, answers, turns, small edits and passing checks alone are
not boundaries. Accumulate related changes. Save documents/decisions/memory
promptly without committing every save. Short tasks usually need one final
commit; long work may preserve independent completed results. Set no
question/file/line/time thresholds.

Exceptions: explicit commit-now instruction or justified checkpoint before
concrete risk. Explain command/risk; preserve workflow gates, isolation and recovery.
Group related steps before dispatch; never bypass a safety transaction.

Before committing read [work safety](references/work-safety.md) and
[message transfer](references/message-transfer.md), then apply
harness/common/skills/comm-check-publication-data/SKILL.md.
Run appropriate checks. Inspect current ownership; the orchestrator commits
only authorized owned changes through explicit file lists, preserving unrelated
work and exclude: paths. No empty/duplicate commits.

Missing Git/compound-engineering:ce-commit, failed checks/commit: preserve changes and report.
Done: hash/subject for completed owned results or clean skip. No push, PR,
merge, history rewriting, route choice or verification upgrade is granted.
