# Сохранение исходных байтов при узком ремонте

Установить область разрешённой правки. Для отсутствующего защищённого входа используют байты опубликованного образца. Если существующий вход расходится с ним, сохранить файл и обратиться к пользователю через INBOX.

1. Для обычного узкого ремонта сохранить исходные байты, декодировать и кодировать UTF-8 без универсальной нормализации. Ошибка кодирования останавливает запись.
2. Сохранить байты вне разрешённого фрагмента. Для новых строк использовать первое окончание строк данного файла, при его отсутствии LF. Глобальную нормализацию согласовать отдельно.
3. Сравнить версию и метаданные перед атомарной заменой временным файлом. Повторный запуск сохраняет байты уже исправленного файла.
4. Перед реализацией или проверкой прочитай файл `harness/common/skills/comm-preserve-text-line-endings/references/regressions.md`. Отчёт отражает фактически проведённые сценарии.
