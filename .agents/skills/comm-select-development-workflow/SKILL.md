# Confirm one workflow route

Apply comm-confirm-development-workflow. Preserve a clear choice for this task.

Read [menu](references/menu.md) for its required options. Use request, context
and brief descriptions. Leave task files and plugin skills unread until selection.
Include every mandatory option. Give a brief reason. Ask for one choice and wait.
Before interpreting replies, read [choice](references/choice.md).

Plain execution keeps Superpowers and CE skills unread, including startup skills.
For a chosen workflow, read its procedures. For full Superpowers,
read [full process](references/full-superpowers.md).
Apply the route within authorized scope and follow mandatory harness instructions.
